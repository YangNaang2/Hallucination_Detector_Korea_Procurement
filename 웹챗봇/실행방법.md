# 실행 방법

## 1. 발표 시연용 — 단일 서버 (권장)

터미널 하나만 띄우면 된다. React 화면과 API 가 같은 주소에서 돌아간다.

```bash
pip install -r requirements.txt
python -m uvicorn api:app --port 8000
```

브라우저에서 **http://localhost:8000** 접속.

프론트 코드를 고쳤다면 빌드를 다시 해야 화면에 반영된다.

```bash
cd frontend
npm install      # 최초 1회
npm run build
```

## 2. 프론트 수정하며 작업할 때 — 개발 서버

터미널 2개.

```bash
# 터미널 1 — 백엔드
python -m uvicorn api:app --port 8000

# 터미널 2 — 프론트 (수정하면 즉시 반영)
cd frontend && npm run dev
```

브라우저에서 **http://localhost:5173** 접속. `/api` 요청은 8000 으로 프록시된다.

## 3. 검사만 하는 Gradio 화면 (기존)

```bash
python app_cpu.py
```

## 답변 생성 (Ollama)

Ollama 와 `gemma3:1b` 는 설치돼 있다. 답변 1건에 **CPU 에서 6~14초** 걸린다.
Ollama 가 꺼져 있으면 목업 답변으로 자동 전환되고, 그때는 말풍선에 배지가 뜬다.
환각 탐지는 어느 경우든 실제 모델이 한다.

`http://localhost:8000/api/v1/health` 로 지금 무엇이 답을 만드는지 확인할 수 있다.
다른 모델을 쓰려면 `OLLAMA_MODEL` 환경변수로 바꾼다.

## 시연할 때 알아둘 것

**민감도 슬라이더** — 낮출수록 많이 잡는다. 기본값 0.15.
0.35(원래 Gradio 기본값)로는 놓치는 게 많고, 0.15 에서도 맞는 답변에는 형광펜이 뜨지 않았다.

**환각 유발 모드** — 체크하면 "지어내지 말라"는 지시를 뺀 프롬프트로 답을 만든다.
평소 프롬프트에서는 모델이 모르는 걸 전부 "문서에 없습니다"로 답해서 형광펜을 보여줄 수가 없다.
다만 이 모드는 temperature 가 높아 **실행할 때마다 답이 달라진다.** 발표 직전에 미리 돌려 보고,
형광펜이 뜨는 질문을 골라 두는 편이 안전하다.

**탐지기 한계** — 환각을 전부 잡지는 못한다(대략 3건 중 1건 수준).
지어낸 문장이 있어도 "발견되지 않았습니다"가 나올 수 있다. 이건 모델 성능이지 고장이 아니다.

## 긴 문서 처리

탐지 모델은 512 토큰까지만 본다. 문서를 통째로 넣으면 창 여러 개로 쪼개지고,
창별 확률이 서로를 눌러 **환각을 하나도 못 잡는다**(실제로 500 토큰이 넘으면 탐지율이 0 이 됐다).

그래서 `api.py` 가 질문과 겹치는 문단만 골라(`select_context`) 창 하나에 들어가게 줄인 뒤
(`fit_for_detector`) 생성과 검사에 함께 쓴다. 덕분에 LLM 프롬프트도 짧아져 CPU 에서 빨라진다.

## 파일 구조

| 경로 | 역할 |
|---|---|
| `app_cpu.py` | 탐지 모델(`Detector`) + 단독 Gradio 화면 |
| `api.py` | FastAPI 서버 — 문서 추출, 답변 생성, 환각 탐지, 정적 파일 서빙 |
| `frontend/src/components/SecureDocChat.jsx` | React 챗봇 화면 |
| `frontend/dist/` | 빌드 결과 (단일 서버가 이걸 서빙) |
| `false_positive_reports.jsonl` | 오탐지 신고가 쌓이는 파일 |

## API

| 메서드 | 경로 | 설명 |
|---|---|---|
| POST | `/api/v1/chat-and-detect` | 문서+질문 → 답변 생성 + 환각 검사 |
| POST | `/api/v1/report-false-positive` | 오탐지 신고 기록 |
| GET | `/api/v1/health` | 탐지기/생성기 상태 |

`/docs` 에서 Swagger UI 로 직접 테스트할 수 있다.
