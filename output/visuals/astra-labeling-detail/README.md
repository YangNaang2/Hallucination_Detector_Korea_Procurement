# ASTRA 환각 구간 라벨링 상세 도해

발표 질의응답과 팀원 교육에 사용할 수 있는 16:9 SVG 9장이다.

1. 전체 과정
2. 평가 대상 정본 고정
3. 생성 당시 근거 복원
4. 주장별 판정 의사결정
5. 최소 구간과 Unicode 위치
6. 사람 검수·조정·승인 단계
7. JSONL 구조와 자동 검증
8. KLUE 학습·평가·서비스 연결
9. 역사 비교·고정 100건·80/85 시연 세트의 차이

모든 SVG는 `build_labeling_detail_svgs.mjs`로 재생성할 수 있다. 문서의 절차는 `project-docs/환각라벨링/pilot-25-v1/GUIDELINES.md`, `pilot-25-human-review-v1`, detector-300 및 KLUE 결과 브랜치를 기준으로 작성했다.

80%·85% 세트는 정답과 예측을 확인한 뒤 비율을 맞춘 사후 구성 시연 자료다. 전체 또는 독립 성능으로 표현하지 않는다.
