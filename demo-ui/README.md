# ORBIT · 나라장터 입찰 검토 UI

## ASTRA 실제 공고 탐색 추가

`spatial-poc/실행.bat`은 이제 실제 공고 탐색 화면을 연다. 표본 51건과 팀원1·3 요건 시트 21건을 연결했으며 사업금액·검색·분야·수집 월·지역·요건 시트 유무로 지도와 목록을 함께 필터링한다. 같은 지역은 공고 수로 묶고 위치 미확인은 목록에 보존한다. 지도는 기관명 지역 대표점으로 실제 사업장·참가기업 주소를 뜻하지 않는다. 기존 가상 공간은 양쪽 화면의 링크로 이동할 수 있다.

데이터 범위·갱신·실행 방법은 [실제 공고 데모 안내](spatial-poc/실제공고_데모_안내.md)에 있다. 아래는 기존 ORBIT 독립 HTML의 설명이다.

`ORBIT_입찰검토_데모.html` 파일을 더블클릭하면 브라우저에서 열립니다.
팀원에게 이 HTML 파일 하나만 보내면 됩니다. 설치와 인터넷 연결은 필요 없습니다.

## 시연 순서

1. 왼쪽 문서 지도에서 4·5·6월 필터와 공고 노드를 선택합니다. 오른쪽 공고 선택 메뉴로도 전환할 수 있습니다.
2. 오른쪽에서 `참가 자격 검토`를 누르고 분홍색 구절을 클릭합니다.
3. 왼쪽 지도에서 금색 참조 청크와 분홍색 선택 청크, 아래쪽 대응 원문을 확인합니다. 작은 노드를 직접 선택해 청크를 볼 수도 있습니다.
4. `제출 일정 확인`으로 의심 구절이 없는 답변 예시를 봅니다.
5. `투찰 전략 조회`를 L2와 L3 사용자로 각각 실행합니다.
6. 문서 보관함과 시연 로그에서 선택 자료 및 작업 내역을 확인합니다.

문서 지도는 천천히 움직이며 마우스를 올리거나 키보드로 노드에 초점을 맞추면 멈춥니다. 일시정지 버튼도 있습니다. 운영체제의 모션 감소 설정이 켜져 있으면 정지 상태로 시작합니다.

큰 점은 공고, 작은 점은 문서 청크입니다. 연결선은 공고와 해당 청크의 소속 관계입니다. 실제 임베딩 유사도나 GraphRAG 결과를 시각화한 것이 아닙니다. 금색 참조 표시와 분홍색 원문 선택은 예시 답변에 맞춰 지정했습니다.

## 구현 범위

- 월별 공고 선택, 예시 답변, 하이라이트 선택, 원문 청크 펼치기, 역할 전환, 시연 로그가 동작합니다.
- 공고·기관·금액·일정·사내 자료는 모두 가상 예시입니다. 수집된 나라장터 데이터를 읽지 않습니다.
- 실제 검색, LLM 답변 생성, 탐지기 추론, 근거 자동 연결, 서버 인증은 미연결입니다.
- 자유 입력은 입력한 질문을 표시하고 모델 미연결 안내를 반환합니다. 예시 질문 버튼은 지정된 시나리오를 재생합니다.
- 단계별 재생 시간은 화면 연출이며 모델 추론 성능을 나타내지 않습니다.
- 역할 선택은 프런트엔드 시뮬레이션입니다. 모든 예시 데이터가 HTML에 있으므로 보안 경계가 아닙니다. 실제 민감 문서를 이 파일에 넣으면 안 됩니다.
- 환각 표시가 없다는 것은 정확성 보장이 아닙니다. 모델 점수·정확도·폐쇄망 인증 등의 미측정 성능은 표시하지 않습니다.

## 다음 연동 지점

1. 청크에는 공고 ID, 수집 월, 원문 파일 ID, 페이지/조항, 청크 ID, 접근 권한, 텍스트를 함께 보존합니다.
2. 백엔드가 로그인된 사용자 권한을 검증하고, 허용 문서만 검색합니다. 프런트엔드의 역할 선택값을 신뢰하지 않습니다.
3. 검색 결과와 질문을 로컬 생성기에 전달합니다.
4. 생성 답변과 동일한 검색 문맥을 탐지기에 입력합니다.
5. 답변 내 시작/끝 좌표로 하이라이트합니다. 근거 청크와 관계 설명은 별도 연결 모듈로 제공하고, 연결되지 않은 경우에는 그 상태를 표시합니다.
6. 원문 열람에서도 서버가 권한을 재검증합니다. 사용자가 바뀌면 이전 답변과 원문 상태를 제거합니다.
