# ORBIT 3D 데모 업데이트

기존 `실행.bat`으로 실행합니다. 이미 열려 있다면 Ctrl+F5로 새로고침합니다.

- 판교·화성·구미에 대전·부산·인천·광주·제주를 추가했습니다. 8곳 모두 가상 공고이며 좌표는 시연용 대표점입니다.
- OpenFreeMap의 OSM 건물 윤곽을 fill-extrusion으로 입체화했습니다. 확대 단계 13.5부터 높이가 점차 드러납니다. 지역별 데이터 누락이 있으며, 높이 속성이 없으면 시연용 8m를 적용합니다. 실제 건물 높이 검증 결과가 아닙니다.
- 지형 강조는 1.7배입니다. 하단 고도도 연출 지형값으로 표시합니다.
- 지역마다 다른 8색과 4가지 게이트 형태, 실제 좌표에 놓인 650m 연출 기둥과 화면상 발광·펄스 장식을 추가했습니다. 기둥은 건물이나 실제 시설이 아닙니다.
- 위치 노드는 카메라를 이동시킵니다. 지도 게이트와 입체 기둥 클릭은 해당 공고를 선택하고 참가 자격·평가 기준을 함께 강조합니다. 평가 점수는 합성 데이터입니다.
- 프리셋은 중간 정지 없는 단일 flyTo로 이동하며 새 선택이나 드래그 시 이전 이동을 취소합니다.

## 성능 조정

래스터 도로 지도를 벡터 레이어로 교체했습니다. 줌 수준에 맞는 벡터 타일과 건물 표시 범위를 사용하고, DEM 요청은 z12까지 제한합니다. 화면 픽셀 비율 상한 1.5, 타일 캐시 100, 이미지 병렬 요청 8, 카메라 수치 업데이트 약 180ms 간격을 적용했습니다. 고해상도 DEM 대신 확대 보간하므로 지형 세부감과 성능의 절충입니다.

별도 requestAnimationFrame/지도 강제 repaint 루프가 없습니다. 펄스는 선택·호버 시 3회만 재생하며 이동 및 탭 숨김 중에는 멈춥니다. 이동 중 HUD 배경 흐림 효과도 끕니다. 실제 FPS 개선율은 아직 측정하지 않았습니다.

## 확인 범위

`node check-interactions.cjs`: 8개 지역 바인딩, 카메라 목적지, 마커 근거 연결, 평가 노드, L1/L3 합성 자료 필터 검사. 지도와 DOM을 대체한 로직 검사이므로 브라우저 화면·GPU 성능·공개 타일 응답을 검증하지는 않습니다.

인터넷과 WebGL 지원 브라우저가 필요합니다. 기존 생성/환각탐지 결과는 여전히 사전 작성 예시이며 실제 모델·서버 권한 검증은 연결하지 않았습니다.

참고: [MapLibre 공식 3D 건물 예제](https://maplibre.org/maplibre-gl-js/docs/examples/display-buildings-in-3d/), [OpenFreeMap](https://openfreemap.org/quick_start/).
