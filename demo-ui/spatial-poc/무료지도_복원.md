# 무료 현실 지도 · 황혼/야간 스타일

기존 터미널을 Ctrl+C로 종료하고 `실행.bat`을 다시 실행하세요. `http://127.0.0.1:8765/`에서 Ctrl+F5로 갱신합니다.

- 현실 지도: MapLibre GL JS + OpenFreeMap. 토큰 없이 실행됩니다. Mapbox SDK·지도 API·환경변수 조회는 현재 실행 경로에서 제거했습니다. 기존 `.env`는 남겨두었지만 읽거나 브라우저로 전달하지 않습니다.
- 기본은 황혼(DUSK): 회청색 건물, 밝은 주요 도로, 청록 녹지, 따뜻한 방향 조명입니다. 야간(NIGHT) 버튼으로 짙은 청색·차가운 건물 조명으로 전환합니다.
- 기본 지도에 포함된 도로 계층·지명·문자 윤곽·아이콘을 유지하면서 색상을 조정했습니다. Mapbox 스타일 파일이나 타일을 사용하지 않습니다.
- 입체 건물은 공개 데이터의 높이를 사용하며 없으면 8m 대체값입니다. 지형은 공개 DEM 1.6배, 음영은 별도 DEM 소스로 렌더링합니다.
- 현실 모드의 별·화면 전체 착색을 제거하고 HUD 투명도 및 중앙 위치 라벨 크기를 조정했습니다.
- 가상 4개 생태계, 설비 단면, PDF, 공고·문서 연결은 유지됩니다.

공개 타일 서버와 인터넷 연결은 필요합니다. Mapbox Standard의 건물 그림자·랜드마크 모델을 그대로 재현한 것은 아닙니다. 실제 건물 데이터 범위는 지역마다 다릅니다.

검증: JS 구문, 기존 인터랙션/모의 검도 검사, 황혼·야간 팔레트 적용 검사. 실제 브라우저 화면·FPS는 미검증입니다.
