# ASTRA 입찰 탐색 데모

`실행.bat`을 실행하고 브라우저가 이미 열렸다면 Ctrl+F5로 갱신합니다. Python·인터넷·WebGL2 지원 브라우저가 필요합니다.

1. 첫 화면에서 사용자 이름으로 **데모 로그인**하거나 **관리자 전술 직행**을 누릅니다. 일반 진입은 L1, 관리자 진입은 L3입니다. 실제 인증 서비스가 아니며 실제 비밀 문서를 넣어서는 안 됩니다.
2. 왼쪽 4개 분야 중 하나를 고르면 해당 가상 공고 카드가 나옵니다. 카드를 선택하면 카메라가 이동하고 오른쪽 상세·그래프·문서 태그가 바뀝니다.
3. 지도 게이트를 누르면 공고 노드와 자격·평가 조항을 강조합니다. 위치/공고 노드는 카메라를 이동하고, 조항 노드는 이동과 함께 근거 드로어를 엽니다.
4. 답변 검토의 **참가 자격** 버튼이나 오류 표시 문장을 누르면 해당 합성 원문 조항을 형광 표시합니다. 닫기 또는 Escape로 닫습니다.
5. 12종 문서 태그는 각각 합성 텍스트를 엽니다. 제안요청과 RFP는 사용자 요청에 따라 별도 태그로 유지했으며 독립적인 공식 문서 분류 체계라는 뜻은 아닙니다.

## 비주얼과 성능

- OSM 건물 익스트루전과 지형 1.6배를 적용했습니다. 높이 속성이 없는 건물은 8m 대체값으로 그리며 데이터가 없는 건물은 생성하지 않습니다.
- 홀로그램은 실제 GLSL 프레넬 셰이더로 그립니다. 시선과 원통 표면 법선의 각도에 따라 투명도가 달라집니다. 청록/라임 색상, 고도 기반 스캔라인, 윗부분 투명도 감쇠를 사용합니다. 물리적으로 정확한 유리 모델은 아닙니다.
- 공개 DEM의 해당 좌표 고도에 기둥을 배치합니다. 기둥 높이 650m는 시연 효과입니다. 지표 링은 위치 마커에 부착한 화면 공간 CSS 장식이며, 실제 지형을 따라 변형되는 메시가 아닙니다.
- 카메라 줌에 따라 원통 12/32분할 LOD와 줌 단계별 건물 높이를 사용합니다. 시야 밖 기둥은 건너뜁니다. 지속 repaint 루프는 없습니다. 지도 이동·자료 로딩 때 렌더링하며, 삼중 링은 선택/호버 때만 3회 재생합니다.
- 픽셀 비율 1.5 상한, DEM z12 상한, 타일 캐시/동시 요청 제한은 유지합니다. GPU·타일 서버·네트워크에 따라 프레임 드랍이 발생할 수 있습니다. FPS를 측정하거나 완전 제거를 확인한 결과가 아닙니다.

## 자료와 확인 범위

공고, 원문 12종, 기관, 자격 요건, 인프라 거리 전부 가상입니다. 인프라 거리는 실제 POI 조회나 측량·경로 탐색 결과가 아닙니다. 실제 나라장터 원문과 모델은 아직 연결하지 않았습니다. 모델이 해당 구간을 판정했다고 해석하면 안 됩니다.

하단 위도/경도는 실제 지도 카메라 중심 좌표입니다. Pitch/Yaw는 지도 카메라 값이며, 지형 고도는 선택 사업장 DEM 기반 연출 고도입니다. 인프라는 선택 사업장의 합성 직선거리 예시입니다.

구문 검사와 `node check-interactions.cjs`의 8지역·카메라 목적지·4카테고리·12문서·권한 시연·드로어·관리자/일반 진입 검사는 통과했습니다. 실제 브라우저 셰이더 컴파일·화면·FPS는 별도 확인이 필요합니다.

기술 참고: [MapLibre CustomRenderMethodInput](https://maplibre.org/maplibre-gl-js/docs/API/type-aliases/CustomRenderMethodInput/), [공식 지형 위 3D 모델 예제](https://maplibre.org/maplibre-gl-js/docs/examples/adding-3d-models-using-threejs-on-terrain/).
