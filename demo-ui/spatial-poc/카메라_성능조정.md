# Reality 조작·성능 조정

무료 MapLibre + OpenFreeMap 유지. Mapbox Standard API를 사용한 것은 아닙니다.

- 이동 curve 1.42 / speed 1.2. 이동 중 목표 피치는 35도, 도착 후 650ms 동안 55도로 전환합니다. 고피치로 수평선까지 타일을 요청하는 부담을 낮춥니다.
- 타일 캐시 100→240, 픽셀 비율 상한 1.5→1.25, DEM 최대 요청 줌 12→11. 캐시 확대는 메모리 사용 증가와 절충이며, DEM 세부 지형은 확대 보간됩니다.
- 휠 비율 1/260, 트랙패드 1/80. 패닝은 감속 5000, 관성 최대 속도 1200, 선형 계수 .2. 드래그 좌표를 임의 배율로 증폭하지 않고 손을 놓은 뒤 관성을 줄였습니다.
- 광역 뷰는 globe projection과 야간 하늘·안개, 상단 장식 별 배경을 사용합니다. 도로를 밝은 색으로 표현하며 실제 야간 위성 불빛 데이터는 아닙니다.
- 평면 Mercator 전용 홀로그램은 줌7 미만에서 생략해 지구 곡률 구간의 위치 왜곡을 피합니다. 마커는 유지합니다.
- 화성 시연 좌표를 사용자 제시값 [127.067,37.208]로 변경했습니다. 특정 실제 사업장으로 검증한 좌표는 아닙니다.
- 좌우 패널 경계를 측정한 padding을 카메라 목적지에 적용합니다. 화면 전체 중앙 대신 패널 사이의 빈 영역 중앙으로 이동합니다.

구문 및 DOM/카메라 모의 연결 검사는 통과했습니다. 실제 화면 정렬과 프레임 개선율은 GPU·네트워크 환경에서 확인이 필요합니다. 프레임 드랍 완전 제거를 보장하지 않습니다.
