# 현실 지도와 가상 메타-트윈

`실행.bat` → 관리자 직행 또는 데모 로그인 → 상단 **VIRTUAL TWIN**.
처음에는 Three.js를 내려받고 도시 메시를 생성하므로 로딩 시간이 있습니다. 이후 현실/가상 전환은 이미 생성한 장면을 재사용합니다. 현실 지도는 현재 MapLibre이며 Mapbox로 변경한 상태는 아닙니다.

## 시연 순서

1. L1 광역: 4개 특구와 에너지 전송 곡선 확인. 마우스 드래그로 회전, 휠로 확대.
2. 특구 선택 후 **선택 공고 · 사옥으로 이동**: L2 사옥 옥상 접근. 지도 속 사옥/포탈을 클릭해도 진입합니다.
3. **서버 랙 50식 증설** 또는 **클린룸 자동화**: L3 내부 단면과 해당 설비 강조. L2를 누르면 외벽 복원.
4. 오른쪽 과업 노드도 같은 설비를 선택합니다. 문서 태그는 12페이지 PDF의 해당 페이지를 드로어로 엽니다.
5. **RFP 제4조**: 요구 실적과 기업 실적의 불일치/충족을 확인합니다. 앞의 3개 특구는 불일치, 에너지 특구는 충족입니다.

공간 L1~L3는 카메라 탐색 단계이며 기존 사용자 권한 L1~L3와 별개입니다. 내부 설비는 실제 기밀 자료가 아닌 공개 합성 시나리오입니다.

## 구현 범위

- Three.js InstancedMesh로 특구별 2,601개, 총 **10,404개 빌딩**. 실제 PointLight 수천 개 대신 셰이더 발광 창문을 사용합니다.
- 최대 200m 인공 구릉 함수와 협곡, 발광 색 그리드 메시.
- 4개 특구의 색: 시안, 앰버, 라임, 보라. 사옥 포탈은 프레넬 기반 투명 셰이더.
- 가상 설비: 특구별 랙 50식과 클린룸 설비 12식. 단면은 외벽 와이어프레임 전환이며 실제 건물 BIM 절단이 아닙니다.
- 카메라 보간과 추가 상승 곡선으로 진입. 렌더링은 이동/드래그/짧은 효과 구간에서만 지속되고 정지하면 IDLE. 탭 숨김/현실 모드 전환 시 중단.
- 하단 FPS는 애니메이션 중 브라우저 렌더 호출 빈도이며 목표 60 FPS의 보증이나 벤치마크 결과가 아닙니다.
- 정답이 고정된 수치 비교 모의 검도입니다. 환각 탐지 모델 정확도 100%를 의미하지 않습니다. GraphRAG도 정의된 관계 시연이며 실시간 검색/추론은 연결되지 않았습니다.

## PDF

`dist/twin-pdfs/T01.pdf`~`T04.pdf`: 특구당 12페이지, 총 48페이지. UI와 동일한 합성 데이터로 생성했습니다. 한글 폰트를 포함하며 실제 나라장터 공고가 아니라는 표기를 넣었습니다.

## Mapbox로 전환한다면

현실 지도만 Mapbox GL JS의 Standard 스타일과 DEM 지형으로 교체하고, 가상 Three.js 장면·문서·UI는 유지할 수 있습니다. Mapbox 액세스 토큰과 서비스 사용 조건 확인이 필요합니다. 공개 브라우저용 토큰을 사용하며 비밀 토큰을 HTML에 넣지 않습니다. 현재 토큰은 제공받지 않아 Mapbox를 연결하지 않았습니다.

MapLibre 커스텀 레이어와 Mapbox의 행렬 전달 규약은 별도 어댑터가 필요하므로 라이브러리 URL만 바꾸면 안 됩니다. 국가·지역별 건물 데이터가 다르므로 한국의 대상 좌표에서 실제 커버리지를 확인해야 합니다.

[Mapbox Standard/GL JS 안내](https://docs.mapbox.com/mapbox-gl-js/guides/migrate/), [Mapbox 3D 건물](https://docs.mapbox.com/mapbox-gl-js/example/3d-buildings/), [Three.js InstancedMesh](https://threejs.org/docs/pages/InstancedMesh.html)

검증: 자바스크립트 구문, 기존 현실 모드 연결 로직, 합성 감사 경계값·정상/불일치, 48개 문서 ID와 PDF 존재 여부. PDF 표본 페이지를 렌더해 한글과 레이아웃 확인. 실제 WebGL 도시 화면 및 FPS는 아직 검증하지 않았습니다.
