# ASTRA 실제 공고 탐색

`실행.bat`을 실행하면 `http://127.0.0.1:8765/public-notices.html`이 열린다. 기존 가상 공간 시연은 화면 오른쪽 위 링크로 이동한다. 실제 공고 화면에는 로그인 시뮬레이션이나 합성 답변을 연결하지 않았다.

## 연결한 자료

- `표본_목록.csv`의 4~6월 정보시스템 구축·운영 공고 51건: 공고번호·차수, 제목, 발주기관, 공고정보 예산, 수집 월, 분야, 수집 마감 정보, 첨부 수, 공식 공고 링크.
- `요건추출시트_팀원1_3_통합.csv`의 작성된 21건: 참가자격·실적·인력·인증·금액·일정·평가·특이조건·근거 위치·검토 메모. 사람의 추출 자료이며 원문 청크나 검증 완료 정답이 아니다.
- 미작성 30건은 기본정보만 표시한다. 가상 기업, 기업 실적, L2/L3 회사 문서, 생성 답변 및 환각 탐지 결과는 표시하지 않는다.

## 필터와 지도

- 사업금액은 공고정보 예산이며 회사 매출이나 투찰가가 아니다. 직접 입력 단위는 억 원, 최소값 이상·최대값 미만이다. 5천만원 미만 / 5천만원 이상 1억 미만 / 1억 이상 3억 미만 / 3억 이상 단축 버튼이 있다.
- 검색·분야·수집 월·기관 지역·요건 시트 유무와 금액 필터는 AND 조건으로 적용하며, 목록과 지도에 동일한 결과를 사용한다.
- 같은 지역의 공고는 하나의 마커와 건수로 표시한다. 반짝이는 공고 마커를 51개 만들지 않는다. 마커 선택은 해당 지역 필터를 적용한다.
- 지리 좌표가 검증된 원천 자료가 없어, 기관명에 명시된 일부 광역 지역만 대표점으로 연결했다. 기관 주소·실제 사업장·입찰 참가기업 위치가 아니다. 학교명이나 사업명을 근거로 주소를 추정하지 않는다. 지역명으로 식별되지 않는 기관은 위치 미확인으로 남겨 목록에서 조회한다. 지역제한 참가자격과도 구분한다.
- 지도는 MapLibre/OpenFreeMap 외부 네트워크와 WebGL이 필요하다. 지도 로딩 실패 시에도 로컬 목록·필터·요건은 사용할 수 있다. 지도 공급자 표시는 유지한다.
- 목록의 수집 마감 정보와 요건 시트의 일정은 서로 다른 출처다. 차이가 있어도 자동 덮어쓰지 않는다.

## 데이터 갱신과 확인

저장소 루트에서 `python demo-ui/spatial-poc/build_public_notices.py`로 공개용 JSON을 다시 생성한다. 원천 첨부와 회사 자료는 포함하지 않는다. 이후 제출본이 통합되면 같은 경로의 통합 CSV를 갱신하거나 생성기의 입력 경로를 변경한다.

`node demo-ui/spatial-poc/check-public-notices.cjs`는 51개 고유 ID, 작성 21건, 금액 경계·잘못된 입력·복합 필터·위치 미확인·지도 집계 일치를 확인한다. 현재 작성 건수 검사는 추가 제출 반영 시 함께 갱신한다.
