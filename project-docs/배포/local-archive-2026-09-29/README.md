## 자료 해석

- 최초 요건시트는 수신 원본이다. 정제·원문 대조 후의 기준 자료는 기존 51건 통합 시트이며 원본을 새 정답으로 사용하지 않는다.
- 80%·85% 명칭의 ZIP은 선별된 시연 자료의 기존 파일명이다. 독립 평가 성능 또는 최신 모델 성능을 새로 검증했다는 의미가 아니다.
- 과거 배포 ZIP은 당시 전달본이다. 최신 실행 코드·설정으로 간주하지 않는다.
- 각 파일은 내용 변경 없이 복사했고 SHA-256으로 동일성을 확인했다. Git 이력에 동일한 파일이 이미 있는 경우 중복 추가하지 않았다.
- 백업 경로는 `.gitattributes`에서 줄바꿈 변환을 비활성화해 원본 바이트와 해시를 보존한다.
- 모델 가중치, 색인 DB, 전체 원천·추출 캐시, 비밀키, 실행 로그·가상환경은 이번 백업에서 제외했다.
- 다른 팀의 참고 발표자료·보고서는 추가하지 않았다.

## 검사 범위

- 신규 파일 28개, 270,866,753 bytes.
- ZIP·PPTX·XLSX 내부 파일과 텍스트 3175개 단위에서 명백한 토큰·비밀키 패턴 및 제외 파일을 확인했다.
- PDF는 추출 가능한 텍스트를 확인했다. 이미지 속 문자·암호화 내용 등 모든 형태의 민감정보 부재를 보장하는 검사는 아니다.
- 상세 경로·해시는 `manifest.json`에 기록했다. 개인 PC의 절대 경로는 기록하지 않았다.
