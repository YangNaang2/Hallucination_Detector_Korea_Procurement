# 로컬 통합 검증 기록 · 2026-09-15

## 실제 실행

- PC: 메모리 약 15.5 GiB, Intel Graphics. 기존 Qwen2.5-1.5B-Instruct Q4_K_M을 CPU llama.cpp로 실행했다. 다운로드·학습·전체 RAG 재실행 없음.
- 모델 파일 해시는 기존 generation_profiles.json과 실행 스크립트에서 대조했다. alias=qwen2.5-1.5b-local, 모델 서버=127.0.0.1:18767, 통합 서버=127.0.0.1:8769.
- HTTP 질문 1회에서 retrieval→delta→detecting→done을 확인했다. 약 58.87초는 이 한 요청의 관찰값이며 일반 지연 시간·성능 지표가 아니다. 기록은 model-smoke.json.
- 브라우저에서 별도 질문 1회를 실제 전송했다. 답변 'AI-OCR 솔루션의 영구라이선스는 2cpu/16core 이상 적용되어야 함.'이 표시됐다. 생성 성공 검증이며 정답 평가가 아니다. 모델 답변에 인용번호가 누락될 수 있으므로 출처 버튼으로 입력 자료를 확인한다. 자동으로 인용을 지어 붙이지 않았다.
- 탐지 체크포인트는 이 PC의 프로젝트 폴더에서 발견되지 않았다. 사용자도 워크스테이션에 있을 가능성을 말했다. 실제 탐지 추론·성능·새 모델 구절의 UI 표시는 미검증이다. 현재 화면에는 탐지 미실시를 표시한다.

- test-rag-ux.mjs: 저장 결과·취소·이전 응답·XSS·인용·Unicode 기존 회귀 통과.
- test-detection-http.mjs: 8개 프로토콜 검사 통과. 잘못된 offset/quote/확률, 순서, 미실시, 취소. 실제 탐지 모델 실행 아님.
- JS 구문 검사 통과. 기존 25문항·300문항·회사 마스터·기존 RAG 실행 결과는 수정하지 않았다.

- 390px 뷰포트 변경을 요청했지만 브라우저는 실제 innerWidth=1280을 유지했다. 모바일 화면은 검증 완료로 집계하지 않았다. 임시 뷰포트 설정은 복원했다.

## 계약과 운영 범위

기존 l1-http-1은 유지하며 integration_version=astra-local-1을 상태에 추가했다. 확장 이벤트는 모델 답변 delta 이후 detecting, 이어서 done이다. request_id/bid/snapshot/seq 검증을 유지한다. done의 detection_result는 status, spans, unchecked_ranges 및 설정 정보를 가진다. 실제 탐지 결과가 없을 때 빈 구절을 정확성 보장으로 표현하지 않는다.

생성 모델에 전달하고 반환한 동일한 근거 텍스트를 탐지기에 전달한다. 질문·문서 접두사, 특수 토큰 구성 및 0/1 라벨은 기존 demo/detector.py와 src/dataset.py를 따른다. 긴 답변은 192토큰 단위로 나누고 근거 슬라이딩 윈도우를 적용하는 연결 정책을 추가했다. 이는 별도로 검증해야 하는 추론 정책이며 이전 F1을 그대로 적용하지 않는다. 32개 답변 분할/64개 근거 윈도우의 계산 제한에 도달하면 미검사 영역을 반환한다. 탐지 worker는 취소·시간 초과 시 종료한다. 실제 가중치에서 이 경로를 실행한 검증은 아직 없다.

생성 취소는 클라이언트를 즉시 중단시키고 서버 cancel 플래그를 설정한다. 모델 읽기 중에는 소켓 read timeout(기본 120초) 또는 다음 이벤트까지 서버 측 정리가 늦어질 수 있다. 모델 서버 자체의 슬롯 취소/하드 타임아웃 보강은 후속 운영 과제다.

내부 검수 API는 별도 로컬 키를 요구하며 CSRF용 공개 토큰으로 접근하지 못한다. 운영용 사용자 인증·회사별 RBAC는 아니다. L2/L3 자유 질문은 연결하지 않았다. 검수 화면은 읽기 전용이며 최종 승인 pending을 유지한다.

## 남은 작업

1. 워크스테이션 학습 체크포인트·토크나이저·학습 설정을 확인하고 실제 탐지 추론을 검증한다.
2. 긴 답변/윈도우/임계값/토큰 위치를 실제 가중치로 검사한다. 승인 전 25문항을 독립 성능 평가로 쓰지 않는다.
3. 모바일 기기 또는 뷰포트 변경이 가능한 환경에서 QA한다.
4. 실제 다중 사용자 인증·L2/L3 RAG·모델 서버 취소 성능은 운영 통합 단계에서 보완한다.
