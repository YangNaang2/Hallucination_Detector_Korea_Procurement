# ASTRA Evidence Graph 45초 시연 순서

1. **0–8초 · 근거 경로**: 질문 노드를 선택하고 공고·문서·근거·인용·답변으로 이어지는 연결을 보여준다. “실제 저장된 연결만 표시합니다”라고 설명한다.
2. **8–20초 · 원본 추적**: 근거 구간을 선택해 오른쪽에서 원문, Unicode offset, 원본 경로와 SHA-256을 보여준다.
3. **20–32초 · 환각 검수**: 상단 `환각 검수`를 누르고 빨간 의심 구절과 회색 검수 초안을 선택한다. 사람 최종 승인이 대기 중임을 짚는다.
4. **32–42초 · 권한과 기업 조건**: 역할을 `bid_analyst`, 회사를 `가상 한빛IT`로 바꾸고 `공고·기업 조건`에서 충족·미충족·자료부족 조건과 합성기업 증빙을 보여준다.
5. **42–45초 · 경계**: “현재 기능은 기존 hybrid RAG 결과를 설명하는 관계 시각화이며 GraphRAG 성능 주장은 아닙니다”라고 마무리한다.
