# 공개 L1 질문 서버 연결 검증
세부 실행·계약·경계·워크스테이션 후속: demo-ui/spatial-poc/L1_SERVER.md.

## 구현 결과
- 51건 L1 읽기 전용 색인 검색 및 로컬 HTTP 질문 API.
- 기본 생성 미연결 / 명시적 테스트 생성 / 향후 모델 SSE 어댑터 분리.
- 질문 화면의 서버 모드·실제 검색 근거·NDJSON·취소·재시도·탐지 미실시 표시.
- 기존 8767 정적 데모 보존, 8768 테스트 서버 별도 실행.

## 검증 범위
실제 로컬 자료: 51공고, L1 167문서·3,002청크의 metadata/hash/offset 검사 및 공고별 검색 범위 검사. 색인 DB 불변 확인.
테스트 전용 자료: 요청/권한 위조, L2/L3/다른 공고/평가 필드, 출처 변조, 모델 모의 SSE, HTTP 출처·토큰·경로, 취소/연결 종료.
JavaScript: UTF-8 1바이트 분할·다중 이벤트, 큰/잘못된 레코드, 잘못된 요청·snapshot·seq·mode, 권한 밖 근거·인용·해시·offset, 최종 정본 불일치.
기존 UI XSS/Unicode/span 검사와 공개 데이터·지도 데이터 검사를 유지한다.

## 브라우저 확인
- 공개 공고 자유 질문 → 실제 키워드 검색 → 테스트 응답 스트리밍 완료.
- 실제 과업내용서 근거 표시, 테스트 생성기에 전달한 근거로 구분.
- 지연 생성 취소 → 미완료 표시, 오류 → 재시도 → 정상 테스트 스트림 완료.
- 답변 정본 복사, 새 답변 형광펜 비활성/탐지 미실시.
- 전송 중 공고 변경 시 이전 답변 초기화.
- 지도 서비스 인증 필터 5건, 실제 3D 지도 로딩 확인.

## 발견·수정
Windows에서 SQLite context manager가 연결 자체를 닫지 않아 테스트 파일 정리가 지연됐다. closing으로 수정했다.
Windows 연결 종료 예외를 처리했다. 실패한 요청을 완료 답변으로 표시하지 않는다.
생성 실패 시 근거가 실제 모델에 사용됐다고 오인하지 않도록 요청용/테스트 입력/완료 생성 입력 상태를 나눴다.

## 미실시
실제 Qwen/Gemma 실행, E5 임베딩, 전체 RAG 재실행, 탐지 모델, 사람 span 승인, L2/L3 서비스 인증, 원격 연결, 배포.
테스트 통과는 실제 답변 정확도·파싱 정확도·환각 없음의 증명이 아니다.

## 최종 검증 기록
서버 17개, JavaScript 스트림 7개 검사 통과. 기존 UI 정본/XSS/span 검사·지도 데이터 검사·공개 projection 9개 검사 통과. 상세 출력은 validation.json.
잘못된 타입 입력을 거절하며 Windows에서 4xx 응답 전 미수신 소량 본문을 정리해 연결 reset 대신 오류 JSON을 전달한다.
노트북 1366×900, 모바일 390×844 확인. 모바일 clientWidth/scrollWidth 375/375. 출처 드로어 및 Escape 닫기 확인.
기존 저장 답변과 형광펜을 다시 확인한 뒤 서버 모드로 전환하면 초안이 제거되고 탐지 미실시로 표시된다.
