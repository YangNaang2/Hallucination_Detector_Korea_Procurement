# 51건 데모 개선 — RAG 연결 구조

## 완료 범위

사용자의 후속 요청으로 추가 49건 선정은 중단했다. 초안과 선정 코드는 로컬 `work/expansion-paused/`에만 보류했으며 공개 데모·Git 산출물에는 포함하지 않는다. 현재 확정 표본 51건만 사용한다.

- 공고 지도: 통합 요건 51건 반영. 이전에는 팀원 1·3의 21건만 표시했다.
- 조건 언급 필터: 지역, 직접생산, 공동수급, 하도급, 서비스 인증. 금액·월·분야·기관 지역·검색과 AND 적용. 조건이 언급된 것과 필수·허용·금지 여부는 다르다.
- RAG 화면: 공개 공고 51개→L1 문서 167개 메타데이터 연결망. 전체 문서 본문을 배포하지 않는다.
- 실제 저장 답변 4개: OCR 라이선스, 방문/복구시간, 인천 지역, 동아보건대 마감. 선택하면 실제 입력 청크·인용번호와 연결한다.
- 형광펜 기본 OFF. 에이전트 초안만 표시하며 사람 승인 pending. 추가 검수 자료는 입력에 소급 연결하지 않는다.
- 공고 링크는 지도 검색으로 이어진다. 기존 지도·야간/황혼·지형·지역별 묶음 표시를 유지한다.

## 숫자와 보안 범위

223문서·3,275청크는 기존 파일럿 전체 색인 manifest 집계다. L1 167/3,002, L2 34/159, L3 22/114. 300문항 중 생성 답변295/정상 차단5는 workstation final_summary.json 기록이다. 이 웹페이지에서 새로 생성하거나 권한 검증한 수가 아니다.

공개 JSON에는 L1 문서 메타데이터와 선정한 4개 L1 답변·입력 근거·검수 초안만 투영한다. L2/L3 문서, 회사 마스터, tenant, 평가 기대답·금지 주장은 넣지 않는다. 기존 25문항 검수 자료를 수정하지 않고 별도 읽기 전용 시연으로 구성했다. 사후 추가 근거는 발췌이며 원래 전체 청크가 아니다.

형광펜에는 명시적 판정 초안이 있으므로 이 공개 시연 JSON도 학습/검색 입력에 넣지 않는다. 인증 서버를 새로 구현하거나 모든 기존 가상 공간 목업의 보안을 감사한 작업은 아니다. 새 페이지의 L2/L3 접근 기능은 제공하지 않는다.

## 검증

- Python 9개 정상·오류 주입 검사 통과: L2 혼입, 다른 회사 문서 ID, 잘못된 offset, 답변 교체, 구절 오프셋, 기대답 유입, 사후 근거의 입력 인용 위장, 실시간 모드 위장.
- JavaScript: 51개 ID·51개 요건, 금액 경계·오류 입력·복합 필터·지역 집계·조건 필터 검사 통과.
- 브라우저: 전체 문서 전환, 답변 인용2→과업내용서, OCR 형광펜 1구절, 동아보건대 추가 근거 분리 확인.
- 지도: 서비스 인증 언급5건→지역 표시2/미확인3, 검색0건, 공고 직접 링크1건 확인. 지도 실제 로딩 확인.
- 모바일 390×844 요청 환경에서 문서 폭375/scrollWidth375 확인. 그래프 내부 가로 스크롤은 의도된 동작. 기본 데스크톱 화면과 모바일 화면을 직접 확인했다.
- 검증 중 SVG 노드 글자 주변을 눌러도 선택되도록 클릭 영역을 수정했다.

자동 검사는 구조·정본 일치를 검증한다. 자유서술 전체의 오류 없음이나 모델 성능을 보장하지 않는다. 49건 확장, 실제 인증·검색·생성 서버 연결, 사람 span 승인과 학습은 남은 범위다.

## 연결 흐름 효과 추가

133959 영상의 촘촘한 연결선과 134455 영상의 빛나는 분기를 참고해 기존 연결선을 따라 작은 광점·짧은 빛 꼬리가 이동하도록 추가했다. 전체 문서 모드에서는 기존 간선 3개당 1개에만 이동 광점을 두고, 노드는 느리게 점등한다. 도착점의 작은 링도 순차적으로 나타난다. 전체 화면 플래시는 사용하지 않는다.

효과는 장식이며 실제 전송·처리량·RAG 실행을 뜻하지 않는다. 흐름 효과 ON/OFF, 운영체제 모션 줄이기, 비활성 탭 일시정지를 지원한다. 문서 참조·클릭 영역·실제 답변 및 근거 데이터는 바꾸지 않았다.

브라우저 확인: 전체 연결선218개 중 이동 광점73개, OFF 시 장식 레이어 숨김, ON 복귀, 답변 경로의 입력[2] 선택→과업내용서 표시 확인. 모션 줄이기/탭 비활성 정책은 코드에 반영했으며 이번 브라우저 세션에서 OS 설정 변경을 통한 재현은 하지 않았다. [흐름 효과 화면](rag-flow.png)
