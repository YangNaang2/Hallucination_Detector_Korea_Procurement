# 나라장터 2026년 4~6월 통합 현황 (메인 분야 선정 자료)

정리일: 2026-09-11. 세 달 목록 파일(bids, chunk_ready)이 모두 재파싱 후 상태로 확보된 시점의 미리보기다.
월별 상세는 `2026-04_수집현황.md`, `2026-05_수집현황.md`, `2026-06_수집현황.md`. 전체 표는 `2026-04to06_분야별_완전공고.csv`.

**이 표는 파일명 규칙으로 문서 종류를 분류한 미리보기다.** 워크스테이션에서 어댑터가 파일 실재·품질까지 검사한 결과(5월 기준 완전 공고 수가 미리보기 대비 약 2~3% 낮음)가 오면 그 숫자로 갱신한다. 순위는 바뀌지 않을 것으로 본다.

**메인 업무구분은 용역**으로 보는 것이 데이터로 뒷받침된다.

## 3. 후보와 판단 기준

분야는 가상 기업 서사가 아니라 데이터 조건으로 고른다. 분야가 정해지면 가상 기업 3~5곳을 그 분야 기업으로 만든다.

| 기준 | 학술연구서비스 | 행사 기획 및 대행 | SW 및 시스템 개발 (+운영·유지관리) |
|---|---|---|---|
| 규모(완전 공고) | 6,064 | 2,323 | 980 (+667) |
| 문서 완성도 | 59% | **68%** | 45~51% |
| 요건 문서 성격 | 제안요청서 위주. 연구 수행 실적·연구원 학위·경력 조건 | 과업지시서 위주. 행사 대행 실적·인력·보험 조건 | 제안요청서·과업지시서. 소프트웨어사업자 신고·시스템 구축 실적·기술자 등급·유지보수 단가 |
| L2/L3 설계 재료 | 실적·인력 중심. 원가·단가 조건은 약함 | 실적·인력·보험. 단가는 견적 위주 | 실적·인력·인증·단가 네 축 모두 명시적 |
| 팀원 검수 난이도 | 주제가 잡다(농업 실태조사~정책연구)해 검수자가 매번 새 도메인 | 비교적 균질 | 균질, IT 배경 팀원에게 익숙 |
| 유의점 | 분야 안 편차가 커서 가상 기업 하나로 묶기 어려움 | 규모 중간 | 규모 가장 작음. 세 달 합산으로는 충분 |

'용역·기타'는 잡다한 묶음이라 메인 분야에는 부적합하지만, 검색 혼입 테스트의 방해 문서로 쓸 수 있다(5월 담당자 의견).

## 4. 결정 후 할 일

1. 세 담당자에게 같은 명령 전달: `prepare.py ... --sector "<확정 분야>"` (어댑터 1단계는 재실행 불필요).
2. 세 달 `sampling.json`의 선정 공고 원본·텍스트를 메인 워크스테이션으로 이동 (③ 단계).
3. OCR 2차는 선정 공고에 이미지 PDF가 포함된 경우에만 해당 문서만 진행 (4월 1,140건·6월 984건 전체 OCR은 불필요).
4. 가상 기업 마스터 스키마에 분야별 자료 항목 채우기.
