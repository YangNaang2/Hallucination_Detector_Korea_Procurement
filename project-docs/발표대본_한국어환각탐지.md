## 슬라이드 1 — 한국어 환각 탐지: 근거가 보이는 AI 상담 챗봇

[왼쪽 챗봇 화면을 가리키며]

"AI 챗봇에게 '청년창업 지원사업, 제가 신청할 수 있나요'라고 물으면 그럴듯한 답이 돌아옵니다.
문제는 그 안에 근거 문서에 없는 말이 섞여 있어도 사용자는 알 수 없다는 겁니다.
화면처럼 지원금을 '최대 1억 원'이라고 답했는데 실제 공고에는 '5천만 원'이라고 되어 있는 식이죠.
이렇게 AI가 지어내는 말을 **환각**이라고 합니다.

환각을 문장·구간 단위로 짚어내는 탐지기는 영어를 비롯한 **7개 언어에는 이미 나와 있는데, 한국어에는 없습니다.**
거대 LLM을 심판으로 세워 검증하는 방법도 있지만, 답변 하나에 수십 번을 호출해야 해서 비용과 지연 때문에 실시간 서비스로는 못 씁니다.

그래서 저희는 **영어 학습 데이터를 한국어로 번역해 한국어판 탐지기를 직접 만듭니다.**
작동은 네 단계입니다.
첫째, 영어 데이터를 환각 구간 표시째 한국어로 번역합니다.
둘째, 작은 한국어 인코더 모델이 답변을 토큰 단위로 훑어 환각으로 의심되는 구간을 지목합니다.
셋째, 그 구간을 근거 문서와 문자열로 대조해 실제로 없는 내용인지 확인합니다.
넷째, 답변 위에 형광펜처럼 색을 칠합니다 — 초록은 근거 있음, 노랑은 정보 부족, 빨강은 근거와 어긋남이고, 클릭하면 근거 문단으로 바로 이동합니다.

기대 효과는 세 가지입니다.
한국어 구간 단위 환각 탐지기로는 **국내 첫 시도**이고,
번역으로 만든 모델이 진짜 한국어 문서에서 얼마나 통하는지 그 **성능 격차를 처음으로 수치화**하며,
형광펜이 그어지는 화면 덕분에 **3분 안에 결과가 눈에 보입니다.**

팀은 다섯 파트로 나눠 진행합니다 — 문서·RAG 챗봇 / 번역 데이터 파이프라인 / 검증 모델 학습 / 평가 / 프론트엔드·진행입니다."

## 슬라이드 2 [보충] — 선행연구와 우리 자리

[질문 예: "이미 있는 것 아닌가요?" / "뭐가 다른가요?"]

"관련 연구는 이미 활발합니다.
**LettuceDetect**가 2025년에 영어·중국어 등 7개 언어를 지원했고, 그 소형 버전 **TinyLettuce**는 1,700만 파라미터 모델로 2,350억 파라미터 LLM을 이겼습니다.
한국어로는 **K-FinHallu**가 유일한데, 답변 한 턴을 통째로 '환각이다/아니다'로만 판정하고 8B LLM을 씁니다. **어디가 환각인지는 짚지 못합니다.**

만드는 방법은 2025년 9월 터키어 연구가 그대로 보여줬습니다.
영어 RAGTruth를 환각 구간 태그째 번역하면 **구간 라벨이 살아남는다**는 겁니다.
저희도 10건을 시험해 13개 구간 전부, **100% 보존**되는 걸 확인했습니다.
학습 비용은 A100 한 대로 12시간, 실습실 A5000 6대면 넉넉합니다.

저희 자리는 여기입니다.
K-FinHallu는 어디가 틀렸는지 못 짚고, 터키어 팀은 번역본으로 학습해 번역본으로만 평가했습니다.
**저희 질문은 '번역해서 만든 모델이 진짜 한국어 문서에서도 통하는가'이고, 아직 아무도 답하지 않았습니다.**"

## 슬라이드 3 [보충] — 무엇으로 배우고, 무엇을 검사하나

[질문 예: "학습 데이터가 뭔가요?" / "학습 문서와 서비스 문서가 다른데 되나요?"]

"비유하면, **정답지와 답안지를 나란히 놓고 답안지에서 정답지에 없는 말에 밑줄을 긋는** 일입니다.

학습 데이터는 **RAGTruth**입니다.
AI가 실제로 저지른 환각 17,790건이 모여 있고, 환각 구간의 시작과 끝이 글자 단위로 찍혀 있습니다.
영어·터키어 선행연구가 모두 이 데이터를 썼습니다.
저희는 태그째 한국어로 옮겨 학습 15,090건, 평가 2,700건으로 나눕니다.

검사 대상 문서는 **대학 학사요람**입니다.
팀 전원이 당사자라서 모델이 뽑은 라벨이 맞는지 **저희가 직접 검증할 수 있기 때문**입니다.
법률·의료는 정오를 판단할 수 없어 뺐습니다.
학습은 여러 도메인 문서로 하고 서비스는 학사요람으로 하는데, 이게 되는 이유는 **모델이 문서를 외우는 게 아니라 답변과 근거 문서를 대조만 하기 때문**입니다.

지금까지 확인한 것은,
RAGTruth 17,790건을 실제로 내려받아 분석했고, 번역 생존 시험에서 13개 구간이 100% 보존됐다는 겁니다.
다음 단계는 실제 번역 모델로 200건을 배치 처리해 보존율을 다시 재는 것입니다."

## 자주 나올 질문 대비 (짧은 답)

| 질문 | 답 |
|---|---|
| "검증하는 것도 AI면, 검증자의 환각은?" | 검증 모델은 생성을 안 하고 **구간 지목 + 인용**만 한다. 인용 구간이 원문에 있는지는 문자열 매칭으로 기계 확인되므로 지어내면 즉시 걸린다. |
| "K-FinHallu가 이미 했잖아요" | 그건 답변 **한 턴 전체**를 판정한다. 저희는 **어느 구간**이 환각인지 글자 단위로 짚는다. 상세는 `K-FinHallu_비교.md`. |
| "왜 학사요람인가요? 법률이 더 임팩트 있지 않나요?" | 팀에 법률 도메인 지식이 없어 라벨의 정오를 검증할 수 없다. 검사 대상 문서는 회의에서 최종 조율 예정. |
| "번역 품질이 나쁘면요?" | 그 격차(①−②)를 측정하는 것 자체가 이 프로젝트의 연구 질문이다. 격차가 크게 나와도 그것이 결과다. |
