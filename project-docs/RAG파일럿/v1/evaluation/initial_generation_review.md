# 최초 생성 답변의 내용 검토

대상: hybrid-llm-v1에서 완료된 3개 답변. 사람 승인 아님. 환각 span 라벨링 아님.

| 질문 | 관찰 | 에이전트 판단 | 조치 |
|---|---|---|---|
| C01-N11-E1 | “한밭대학교 공고의 분류번호는 변경할 수 없습니다”라는 한 문장. 원문 코드·품명을 보존하고 별도 확인해야 한다는 범위와 인용이 빠짐 | 불완전. 모든 정정 자체가 불가능하다는 뜻으로 확대해서는 안 됨 | 긴 자료 뒤에 실제 질문과 출력·인용 지침을 재명시 |
| C01-P01 | C01-PRJ-01 금액을 “C01-PRJ-04의 실적 금액 하한”과 비교했다고 답함 | 잘못된 비교. 공고의 7천만원 하한과 지정 실적을 대조해야 함 | 명시된 실적 ID와 다른 같은 종류 entity를 검색에서 제외. 여러 ID를 명시하면 모두 유지 |
| C01-S01 | 0036 가정이 “기존 한빛IT 원장에도 적용됩니다”라고 답함 | 잘못된 상태 해석. 원장 not_held는 보존되고 별도 합성 분기만 적용됨 | 원장 불변·가정 분리 원칙을 긴 문맥 뒤 출력 지침에도 명시 |

관찰한 첫 두 실패에 대응해 실행을 중단하는 동안 세 번째 답변까지 완료됐다. 세 답변은 원래 실행 파일에 그대로 보존한다. 나머지 문항이 이 설정에서 완료된 것처럼 집계하지 않는다.

수정은 질문 ID별 정답 삽입이 아니다. 질문에 명시된 entity와 문서 구조를 이용한 검색, 모든 질문에 공통인 인용·상태 분리 지침이다. 기대답·관리자 근거는 여전히 모델 입력에서 제외한다. 수정 후 성공 여부는 별도 실행 결과로 확인한다.
