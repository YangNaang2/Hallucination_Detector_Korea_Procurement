# W384 신규 300 Q·A·R 실행 사전 명세

- run ID: `window384-gpu-v1`
- 기존 W460의 정본 답변·근거·평가를 변경하지 않는다.
- 고정 300문항 전부를 결과 확인 전에 4개 shard로 round-robin 배정한다.
- Parent 1,800자/overlap 240자, Window 384/stride 344, lexical+dense RRF, top6 검색·top4 생성 근거를 사용한다.
- Qwen3-4B Q4_K_M, temperature 0.7, top_p 0.8, top_k 20, 최대 768토큰과 기존 프롬프트를 유지한다.
- 생성 가능 295건은 새 답변을 저장하고 정상 접근 차단 5건은 LLM 미호출을 확인한다.
- 생성기에는 기대답·라벨·기존 답변을 전달하지 않는다.
- 최신 시도는 실패를 포함해 그대로 선택하며 좋은 결과만 남기지 않는다.
- 실행 완료 후 W460 대비 검색 근거·답변 상태·내용 검토를 분리한다.
- 새 답변의 환각 탐지는 생성 후 별도 산출물로 실행한다.
- 사람 최종 승인 전 내용 판정과 환각 라벨은 잠정 결과다.
