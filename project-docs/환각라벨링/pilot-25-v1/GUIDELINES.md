# 환각 구절 라벨링 기준 v1

## 판단 단위와 근거 범위

대상은 원시 `actual_answer`의 실제 문자열이다. 질문, 허용된 생성 시점 입력 문서, 합성 시나리오와 기준일을 함께 읽는다. 기대답은 누락·업무 정확성의 보조 기준이며 그 자체가 원문 증거는 아니다.

모델이 본 문서에 대한 지지 여부와 실제 업무 원문의 정합성을 구분한다. 추가 발견한 원문은 별도 `reference_only_not_in_prompt`로 남긴다. 검색 누락 때문에 보지 못한 조건을 답변에 없다는 이유만으로 환각 구절로 만들지 않는다. 실제 조건 충돌은 어느 쪽이 최종인지 임의 결정하지 않는다.

## 구절 분류

| 코드 | 판정 | 예시와 경계 |
|---|---|---|
| CONTRADICTION | 입력 근거와 모순 | missing을 증빙 존재로 표현, 서비스 보유 주체를 회사로 변경, 매출대비 마진을 원가 가산율로 적용 |
| UNSUPPORTED | 주장을 지지하는 입력 근거가 없음 | CPU/core 사양을 가격 산식으로 변환, 합성 용량 초과를 불법으로 확정 |
| CITATION_ERROR | 출처 번호·페이지·연결 오류 | 제공 번호가 1·2인데 [3]을 인용, 실제 1쪽 조항을 2쪽으로 지칭. 환각 BIO 목표와 별도로 관리 |
| UNCERTAIN | 의미·범위가 모호하여 사람 판정 필요 | effective_until과 valid_until을 해당 시나리오에서만 같은 의미로 썼는지 일반화했는지 모호 |

UNSUPPORTED는 현실에서 거짓이라는 법률·사실 판정이 아니다. 검토한 입력이 지지하지 않는다는 의미다. 일반 상식·상투적 유보 문구를 무조건 환각으로 표시하지 않는다. 실제 법적 결론이 필요하면 별도 원문과 전문가 확인이 필요하다.

## 환각 구절이 아닌 품질 문제

- **누락**: 계산 금액을 묻는데 산식만 답한 경우. 존재하지 않는 답변 구절을 만들지 않는다.
- **잘림**: finish_reason=length 및 실제 768토큰 기록은 출력 한도 문제다. 잘리기 전 오류 주장은 별도로 표시할 수 있다.
- **반복**: 반복 자체는 품질 문제다. 반복 내용도 거짓/근거 없음이면 각 실제 출현 위치에 라벨링한다.
- **검색 누락**: 모델 입력에 없는 중요 조건. 입력 밖 참조와 생성 오류를 구분한다.
- **권한 차단**: 기존 5개는 별도 보안 평가. 이 25개 생성 답변 초안에 섞지 않는다.

## 구절 경계

0부터 시작하는 Unicode code point 위치, `[start, end)`로 저장한다. 원시 답변의 Markdown, 공백, 줄바꿈(LF), 오타를 그대로 포함한다. Excel 줄 번호나 UTF-8 바이트 수가 아니다. JavaScript 문자열의 UTF-16 인덱스와도 다르므로 변환 시 검증한다.

잘못된 의미를 유지하는 최소한의 명사구/서술절을 선택한다. 올바른 주변 문장을 통째로 칠하지 않는다. 숫자의 산술 자체가 맞아도 적용 범위·VAT·마진 의미가 틀리면 그 계산의 역할이 드러나는 구절을 선택한다. 소계 15,200,000원이 맞다면 그 숫자 자체를 거짓으로 만들지 않는다.

맞는 첫 결론 뒤에 거짓 설명이 있으면 거짓 설명만 표시한다. 반대되는 첫 결론과 올바른 후속 근거가 함께 있으면 잘못된 첫 결론을 표시한다. 동일 오류의 반복 위치를 누락하지 않는다. 다른 라벨이 겹칠 때는 무리하게 하나로 합치지 말고 조정 대상에 남긴다.

## 합성 자료와 날짜

synthetic_record는 실제 발급 증명서가 아니다. 대장 생성과 증빙 확보, 인증 갱신 가정과 실제 갱신을 구분한다. 적용 시작 전/종료 후 상태를 소급하거나 자동 연장하지 않는다. 회사 인증과 서비스 인증의 보유 주체·버전을 확인한다.

입사일, 배치 시작일, 문서 상태 기준일, 공고일은 서로 다르다. 인력의 FTE 용량과 일할 공수도 구분한다. 원문충돌은 확인 필요로 남기며 실제 조건을 임의 합성해 해결하지 않는다.

## 검수·승인·학습 전환

에이전트 초안, 사람 검수, 최종 조정 승인은 다른 단계다. 이 패키지는 모두 사람 승인 pending이며 `training_ready=false`, `approved_spans=null`이다. 빈 초안은 무조건 음성 정답이 아니다. 모호한 후보와 검수되지 않은 토큰은 학습에서 마스킹하거나 제외해야 한다.

25개는 의도 표본이고 이전 개발에 노출된 자료다. 이 패키지로 독립 Span F1이나 환각률을 주장하지 않는다. 확대 전 팀원 2명이 대표 사례를 독립 검토하고 차이를 조정한다. 이후 공고·시나리오 기준의 누출 방지 분할 및 토크나이저 offset 변환을 별도로 검증한다.
