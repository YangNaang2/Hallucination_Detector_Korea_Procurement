# KLUE 전체 근거 학습 개선 결과 — v3

## 결론

**KLUE 하나의 문자 F1은 22.72%에서 31.13%로 8.41%p 개선됐다. 목표 문자 F1 80%는 달성하지 못했다.** 규칙·앙상블 없이 KLUE만 사용했다. 개발 데이터 F1은 27.24% → 37.56%이다.

미승인 통합 조정안과 이미 노출된 기존 비교용 63건에 대한 잠정 결과다. 최종 사람 승인 라벨은 0건이며, 독립 검증된 성능으로 주장할 수 없다. 최종 사람 기준 점수는 N/A다. 80%의 기준을 문자 F1로 유지했으며, 정상 문자가 많은 자료의 문자 accuracy로 목표를 바꾸지 않았다.

놓친 오류 문자는 310개 줄고 오탐 문자는 306개 늘었다. 총 오류 FP+FN은 3,933 → 3,929로 거의 동일하다. F1 상승만으로 사용자 검수 부담이 크게 줄었다고 볼 수 없다. 답변 단위 TP/FP/FN/TN은 32/21/3/7이며 정밀도 60.38%, 재현율 91.43%이다. 답변 단위 정확도는 오히려 떨어졌다.

문자 평가는 22,722개 위치에서 수행했다. 답변 전체 29,867자, 마스킹 446자, 토크나이저 공백 제외 등의 기존 정책을 동일하게 적용했다. 불리한 구절을 제외하거나 라벨을 수정하지 않았다. 공고 단위 paired bootstrap 2,000회에서 F1 차이의 조건부 95% 구간은 +3.45~+12.20%p이다. 이 구간은 라벨 오류나 개발 자료 재사용의 편향을 반영하지 않는다.

## 실행한 변경과 선택

- 기존 공고 그룹 분할: train 182 / dev 50 / historical comparison 63 유지.
- 원본 KLUE에서 시작하여 하위 6개 층과 임베딩은 고정하고 상위 층을 3 epoch 추가 학습했다.
- 이전 top-2 근거 window 각각에 라벨을 부여하던 근사 대신, 실제 전체 근거 window의 답변 토큰 logit 최소값에 BCE loss를 적용했다. 정답 구절의 지지가 한 근거에 있으면 충분하다는 가설이다.
- 양성 가중치를 2에서 1로 변경했다. 학습률 5e-6, seed 916, window microbatch 4. 총 331개 답변 구간 묶음, epoch별 저장·재개를 지원한다. 중간 epoch 중단 시 그 epoch는 다시 학습한다.
- 개발 정밀도 ≥40%에서 최대 문자 F1을 선택했다. 3개 checkpoint의 raw 집계 탐색과 기존 epoch2를 포함한 raw/문장평균/절평균 탐색을 수행했다. 후자의 1,512개 설정은 개발 데이터만 사용했으며 과적합 위험이 있다.
- 선택: **mil3 / repeat192 / min2 / threshold 0.5 / 후처리 없음 / 규칙 없음**. min2는 근거 window 확률 중 두 번째 작은 값이며 window가 하나면 그 값을 쓴다.
- 추가 학습 raw 최선 개발 F1: mil1 24.37%, mil2 20.91%, mil3 37.56%. 문장·절 평균 후처리는 최종 선택에서 제외했다.
- 선택을 `76d9b1e`에 커밋한 뒤 기존 63건 비교를 실행했다. 결과를 보고 추가 임계값을 선택하지 않았다.
- objective, 가중치, update 빈도 등이 함께 달라졌으므로 개선을 한 요소의 효과로 단정하지 않는다. 기존 비교 데이터는 v2에서 이미 노출되어 새 holdout이 아니다.

## 라벨 재검토

기존 295건 초안과 pilot 25 제출·조정안을 보존했다. 이전 모델의 학습 자료 오탐 상위 3건을 당시 실제 근거와 다시 대조했다. 마감일 표현의 경계 판단 제안, 하드웨어 유지관리의 조건부 표현·인용번호 구분, 근거에 없는 제안서 평가 불이익 주장을 `label_rereview.json`에 기록했다. 검토 대상 선택에 모델 오탐을 사용했으므로 독립 라벨 감사 표본은 아니다.

에이전트 재검토 제안이며 사람 승인으로 바꾸지 않았다. 이번에 295건 전체를 새로 재검수했다는 뜻도 아니다. 점수에 유리하게 채점 라벨을 변경하지 않았다. 사용자가 295건을 처음부터 다시 라벨링해야만 실험할 수 있는 것은 아니지만, 이 결과로 검증된 80%를 주장할 수는 없다.

## 자원·검증

RTX A5000에서 학습·추론했다. 새 3 epoch 학습 루프 총 83.5초(모델 초기화·토큰화·저장 제외), 선택 모델 295건 추론 합계 62.44초, 5,196 windows, 최고 torch allocated 0.615 GiB이다. 학습 peak VRAM은 계측하지 않았다. 기존 서버 및 기존 모델 작업은 보존했다. XLM-R/BGE-M3를 재실행하지 않았다.

별도 운영 경로 검증에서 모델 1회 로드 5.89초, warmup 0.34초를 측정했고 3문항의 예측이 실험 캐시와 동일했다. 선택 모델 295건 모두 저장했으며 재실행은 완료 건을 건너뛴다. 입력 체크 300건 통과, 자동 테스트 38개 통과, 원본 답변/근거/라벨/가중치 및 기존 v1/v2 결과 보존, 전체 비공백 검사영역 동일성을 확인했다. 정상 차단 5건은 기존 별도 검증을 유지했고 탐지 학습·추론에 넣지 않았다.

## 남은 목표

80% 달성은 미완료다. 추가 계산만으로 도달할 수 있다는 근거가 없다. 다음 검증에는 아직 학습·선택에 사용하지 않은 조달 답변과 실제 생성 당시 근거, 신뢰 가능한 구절 라벨이 필요하다. 정상 패러프레이즈·조건/예외·모순에 대한 학습 자료 보강도 후보이나 이번 결과로 효과가 검증된 것은 아니다. 현재 자료의 추가 튜닝과 독립 성능 검증을 구분해야 한다.
