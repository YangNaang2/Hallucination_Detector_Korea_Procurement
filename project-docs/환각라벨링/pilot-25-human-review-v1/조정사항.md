# 최종 조정자가 확인할 사항

## 근거 대조로 반영한 조정 제안

- C04-P04의 두 구절: actual_contract_start=null을 확정 사실로 바꿨으므로 UNSUPPORTED → CONTRADICTION 제안.
- C01-N43-E4-S01: 재하도급 원칙적 불가를 제한 범위 내 허용으로 확대하므로 CONTRADICTION 제안. 결론 자체와 뒤의 잘못된 유보를 분리한다.
- C05-S03의 두 인용: [1]은 P-04 한 명이며 P-07/P-06은 [2]/[3]에 있다. 인력 사실 자체가 허위라는 뜻이 아니라 출처 연결 오류다.
- C04-P01: 회사 ISO 레코드가 두 인증의 비대체 관계를 '명시한다'는 주장은 제공 자료에 없다. 올바른 결론이라도 근거 명시 주장은 별도 검토한다.
- C02-S01: '기존 유효 상태'는 근거의 기존 만료 상태와 반대다. 표기 기준 CONTRADICTION 조정안을 제시하되 최종 승인 전이다.
- C01-N43-E4: 완성된 조항 번호 9개를 CITATION_ERROR로 제안했다. 팀원은 3개를 명시적으로 제안했고 나머지 6개는 에이전트가 동일 유형으로 추가했다. 끝의 잘린 '- [2] 제2항'은 라벨을 붙이거나 삭제하지 않았다.

## 신규 제안 중 보류한 5개 구절

| 문항 | 쟁점 | 에이전트 제안 |
|---|---|---|
| C04-N08-E2 | '법적 근거가 없다'가 해당 공고 설명인지 법률 일반 주장인지 | UNCERTAIN 유지 |
| C01-S03 | '능력이 있다'가 월별 공수 질문을 자원 능력으로 오해한 답변 | 기존 명백한 한 달 적용 오류는 유지, 짧은 표현은 UNCERTAIN |
| C01-N01-E1 | 금액·단가 미제공을 이유로 '확정 불가' | 질문 가능 여부와 금액 산정의 혼동. 구절 전체를 모순으로 단정하지 않고 UNCERTAIN |
| C02-P02 | 합성 유지관리 인증이 '유효한 상태' | 합성 날짜 범위의 유효인지 실제 증빙 유효를 뜻하는지 불명확. synthetic_record 자체가 무효를 뜻하지 않음 |
| C03-N48-E1 | RFP를 '공고문'이라고 지칭 | 특정 파일 귀속 오류인지 첨부문서 통칭인지 불분명. 문서 시각 충돌은 별개로 유지 |

기존 C04-S03 1개와 C05-N09-E2 반복 10개도 UNCERTAIN을 유지하여 보류는 총 16개 위치다. 문항 수는 7개다. 동의가 입력되었다고 보류를 환각 정답으로 전환하지 않았다.

## 환각으로 단정하지 않고 품질 메모로 둔 2개

- C02-P02 '모두 만료된 것이 아닙니다': 이후 문장에서 개발 만료·유지관리 미만료를 구분하므로 문맥상 부분부정이 성립한다.
- C03-P04 '0.9 FTE를 초과하지 않으므로': 0.5+0.4=0.9로 문장 자체는 참이다. 더 좋은 근거는 가용 1.0 FTE와 비교하는 것이지만, 비교 설명의 부실을 새로운 허위 수치로 라벨링하지 않는다.

이 둘은 확정 정답/O 학습 라벨도 아니다. 전체 문항 최종 승인 때 다시 확인한다.

## 문항·검수 의견의 별도 쟁점

- **C02-S03**: 신규 배치 0.51 FTE를 추가한다는 뜻과 기존 0.5를 0.51로 바꾼다는 뜻이 섞일 수 있다. 원본 질문은 보존하고 다음 버전에서 '신규 과업에 추가로 배치할 총량'이라고 명확히 할 것을 제안한다.
- **C02-N46-E2**: '전국 제한'이라는 전제와 대구 본점 RFP의 관계·우선순위가 미해결이다. 입력 밖 RFP를 당시 모델 근거로 취급하지 않는다.
- **C03-N48-E1**: RFP 10:00과 공고서 11:00 충돌은 이 검수만으로 해결되지 않는다. 어느 시각이 최종이라고 임의 확정하지 않는다.
- **T04 C01-N43-E4 의견**: 앞에서는 결론이 근거와 맞는다고 하고 뒤에서는 모순이라고 적었다. '원칙적 불가'와 부합하는 결론과 과잉 허용을 주장하는 유보를 구분하는 것이 조정안이다. 답변 꼬리를 삭제하자는 표현도 원문 삭제로 실행하지 않았다.
- **T01 반복 위치 메모**: 여러 행의 '두 번째 출현'은 복사된 것으로 보인다. 위치는 원래 span ID와 정본 offset으로 유지했다.
- **T04 수정 J칸 공란**: K칸에 범위 유지·분류 변경이 명시돼 해당 제안을 추출했다. 미작성 J칸을 사람이 작성한 것처럼 채우지 않았다.

제출 의견의 재검토 1건은 C02-N46-E2다. 이것이 보류 구절 16개나 최종 승인 대상 25건과 같은 집계는 아니다.
