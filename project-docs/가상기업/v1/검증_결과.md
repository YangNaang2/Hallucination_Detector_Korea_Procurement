## 경계와 반례

- 원문 하한 70,000,000원(VAT 포함)에 합성 실적 70,000,000원은 금액 조건 충족, 69,999,999원은 미충족. 전체 실적 인정 건수는 계산하지 않았다.
- C02 개발 직접생산 인증은 2026-03-31까지 유효하며 2026-04-01에는 만료로 처리한다.
- C04 서비스 CSAP는 날짜·증빙이 없는 missing이다. 회사 ISO 인증을 가져와 유효로 처리하지 않는다.
- 기존 0.5 FTE 인력에 0.5 FTE를 더한 테스트는 통과, 0.51 FTE를 더한 테스트는 거부한다. 이 수치는 시나리오 설정·계산값이다.
- 다른 회사의 bid_approver도 C01 L2/L3 접근이 차단되는 규칙을 확인했다. cost_analyst는 자기 회사 원가는 읽되 투찰전략은 읽지 못한다.
- 기대답 필드를 후속 문서 스키마에 넣거나, 미검수 문서에 색인 허용을 켜거나, 청크 tenant/문자 offset을 바꾼 테스트를 거부한다.

## 해석의 한계

- 테스트 수는 소프트웨어 검사 결과이며 모델 정확도·입찰 오판율·보안 완성도를 나타내지 않는다.
- `synthetic_record`는 원장 레코드가 있다는 뜻이다. 실제 증빙 파일·인증기관 조회·공식 실적 확인은 하지 않았다.
- HWP 쪽수는 미확인이다. 인천 PDF 누락 표는 뷰어 3쪽을 직접 확인해 지역 조건을 해소했다. 시각 전사에 가짜 문자 offset을 만들지 않았다. 이번 근거를 벗어나는 미확인 공고 요건은 확정하지 않았다.
- 공고 연도·정정 우선순위 문제를 코드로 임의 해결하지 않았다. 웹툰아카이브 기간 기반 최종 집계는 보류 상태다.
- 실제 RAG 문서 생성·벡터 색인·서버 세션·권한 필터·LLM 답변 생성·span 라벨링은 후속 작업이다.

## 재현

저장소 루트에서 `python procurement-pipeline/validate_company_master.py`를 실행한다. 원본 대조를 재현하려면 로컬 `source-texts.json`과 `export` 상위 폴더를 각각 `--source-cache`, `--source-root`로 지정한다. 생략 시 해당 원문 검사는 not_run으로 보고된다. 원본은 커밋하지 않는다.

`procurement-pipeline`에서 `python -m unittest -v test_company_master.py`를 실행한다. 외부 패키지 없이 동작하며, 데이터가 바뀌면 JSON 검증 결과와 이 요약도 다시 갱신한다.
