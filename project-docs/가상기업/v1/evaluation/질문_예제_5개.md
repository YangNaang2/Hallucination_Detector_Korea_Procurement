# 질문·기대답·근거 예제 5개

**대상:** R26BK01487327 / 000, 가상 한빛IT(C01), SC-WB-C01 단독 참여 초안. 원장 버전 1.0.0 / 기준일 2026-04-01. 공개 공고는 이후에 나온 과거 테스트 입력이다. 회사 상태 기준일을 공고일로 대신하지 않는다.

**접근 상황:** 로그인한 astra-c01 소속 bid_analyst가 L1과 자기 회사 L2만 조회한다. 아래 기대답은 offline_evaluator용이며 RAG에 넣지 않는다. 실제 생성 답변·환각 span은 미생성이다.

## Q001 — 충족

**질문**

C01-PRJ-01의 계약금액은 이 공고의 실적 금액 하한을 만족하나요? 금액 조건만 비교해 주세요.

**기대답**

부가세 포함 70,000,000원으로, 원문의 단일 계약금액 7천만원 이상 경계와 같으므로 금액 조건은 충족합니다. 최근 3년·유사성·증빙 제출 및 전체 적격 여부는 별도 검토입니다.

**근거 연결**

- 원문: [S-WB-AMOUNT](../공고_회사_조건연결표.md#s-wb-amount)
- 회사 원장: `/companies/0/projects/0`
- 합성 증빙: `SYN-EV-C01-PRJ-01`
- 포함할 판단: 금액 조건 충족 / VAT 포함 / 전체 적격 아님
- 해서는 안 되는 주장: 실적 최종 인정 완료 / 입찰 적격 확정
- 정량 성능·최종 입찰 적격·실제 발급 여부는 평가하지 않음.

## Q002 — 미충족

**질문**

C01-PRJ-02의 69,999,999원을 7천만원으로 반올림해서 실적 금액 조건을 만족한다고 해도 되나요?

**기대답**

아니요. 부가세 포함 69,999,999원은 70,000,000원보다 1원 작아 해당 실적의 금액 조건을 충족하지 못합니다. 이 결과만으로 회사 전체의 입찰 참가 불가를 판정하지 않습니다.

**근거 연결**

- 합성 증빙: `SYN-EV-C01-PRJ-02`

- 해서는 안 되는 주장: 7천만원 이상 충족 / 전체 입찰 탈락
- 정량 성능·최종 입찰 적격·실제 발급 여부는 평가하지 않음.

## Q003 — 자료부족

**질문**

C01-PRJ-03은 1억 2천만원이니 증빙이 없어도 인정 실적에 넣을 수 있나요?

**기대답**

**근거 연결**

- 합성 증빙: `SYN-EV-C01-PRJ-03`

- 해서는 안 되는 주장: 증빙 확인 완료 / 120000000원이므로 자동 인정
- 정량 성능·최종 입찰 적격·실제 발급 여부는 평가하지 않음.

## Q004 — 미충족

**질문**

한빛IT가 단독 참여할 때 정보통신공사업 0036 조건을 충족하나요?

**기대답**

합성 마스터에서 한빛IT는 0036을 보유하지 않아 단독 참여 모드의 이 조건은 미충족입니다. 원문에는 분담이행 가능 조항이 있으므로 별도 공동수급 구성을 검토할 수 있지만, 협정이나 구성원 자격이 자동 확보되는 것은 아닙니다.

**근거 연결**

- 원문: [S-WB-0036](../공고_회사_조건연결표.md#s-wb-0036)
- 회사 원장: `/companies/0/registrations`, `/companies/0/known_absences`
- 합성 증빙: `SYN-EV-C01-NO-0036`
- 포함할 판단: 0036 미보유 / 단독 모드 / 분담이행 별도 검토
- 해서는 안 되는 주장: 1468로 0036 대체 / 공동수급 자동 승인
- 정량 성능·최종 입찰 적격·실제 발급 여부는 평가하지 않음.

## Q005 — 원문충돌

**기대답**

현재 자료만으로 최종 건수와 점수를 확정하지 않겠습니다. 제출 일정은 2026-05-15이지만 공고문 말미는 2025-04-24로 표기되어 있습니다. 공식 게시일·정정 공고를 확인해 기준일을 확정하고 증빙 상태도 확인해야 합니다.

**근거 연결**

- 원문: [S-WB-AMOUNT](../공고_회사_조건연결표.md#s-wb-amount), [S-WB-YEAR](../공고_회사_조건연결표.md#s-wb-year), [S-WB-DEADLINE](../공고_회사_조건연결표.md#s-wb-deadline)
- 회사 원장: `/companies/0/projects`
- 합성 증빙: 해당 없음
- 포함할 판단: 2026-05-15 / 2025-04-24 / 기준일 확인 후 계산
- 해서는 안 되는 주장: 공고일을 2026-04-24로 확정 / 전체 실적 최고점
- 정량 성능·최종 입찰 적격·실제 발급 여부는 평가하지 않음.

## 파일럿에서 수정한 설계

원문에 명확한 금액 하한이 있어 Q001/Q002의 경계 비교를 유지했다. 반면 최근 3년의 기준일은 공고문 연도 표기 때문에 확정할 수 없어 Q005를 판단 보류 문제로 바꿨다. Q003은 금액 조건과 증빙 조건을 분리하고, Q004는 단독 참여와 분담이행 가능성을 구분한다.

이 5개는 규칙·근거 연결 파일럿이며 학습용 300건이나 span 정답지 300건 완성을 의미하지 않는다. 실제 모델 답변을 받으면 해당 답변의 문자 위치를 기준으로 별도 span 레이블을 만든다.
