# 팀원1 보완 및 팀원1·3 통합 내역

팀원1 제출 CSV를 보완하고, 팀원3 검토수정 XLSX의 10건을 공고번호로 병합했다. 51건 중 팀원1 11건 + 팀원3 10건 = 21건 작성, 다른 팀원 30건은 미작성 상태 그대로다. 제출 원본과 팀원3 수정본은 변경하지 않았다. 기존 15개 열·행 순서·공고 기본정보를 유지했다.

이번 보완은 제출 시트의 내부 일관성 정리다. 원천 공고 HWP/PDF 전량 재검증이나 법령 현행성 확인을 수행한 결과가 아니다. 미확인은 원문·정정공고·회신을 확인할 때까지 확정 정답에 사용하지 않는다.

| 팀원1 원본 셀 | 보완 내용 |
|---|---|
| M11 | 우선순위 단정과 메모의 모순을 확인 과제로 전환 |
| O11 | 본문과 메모의 우선순위 판단 일치 |
| N11 | 확인·미확인 쪽수 혼재 및 확인 주체 표시 |
| G6 | 자격 제한 없음과 최소 실적 요구의 관계 보류 |
| O6 | 실적 없는 기업 정답 생성 보류 |
| K7 | 기산점 및 일수·개월 동일성 단정 제거 |
| O7 | 기간 차이 검토 과제 추가 |
| O3 | 100점 평가표와 90점 반영을 오류로 단정하지 않음 |
| L3 | 점수 환산의 확인 범위 명시 |
| H8 | 인력 점수 구간의 경계 중복 보류 |
| H10 | 인력 환산 점수의 경계 중복 보류 |
| O8 | 조건 없는 대략적 기간 차이 수치 제거 |
| L8 | 법령 날짜 해석을 공식 출처 재확인 대상으로 분리 |
| O12 | 외부 출처가 없는 현행 법령·조직 개편 판단 제거 |
| O7 | 수집 누락 원인 추정 제거 |
| O9 | 수집 누락 원인 추정 제거 |
| O2 | 일반 표현과 구체적 계약방식 표기의 차이로 분류 |
| O2 | 보편 조항 병존·평가 구성 자체를 오류로 취급하지 않음 |

점수 구간은 원문 수치를 임의 수정하지 않고 경계 포함 여부 미확인으로 표시했다. 팀원3의 10건은 이전 검토수정본 값과 전 셀이 동일함을 확인했다. 팀원2·4·5의 미작성 행은 기존 작성 자료를 덮어쓰는 용도로 사용하지 않는다.
