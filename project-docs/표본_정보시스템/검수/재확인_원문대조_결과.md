## 외부 확인이 남는 범위

1. 법원대표전화안내센터와 부산올랭의 제안요청서는 전달된 압축파일에 없다. 두 건의 해당 미확인 요건을 채우려면 누락 RFP 확보가 필요하다. 원문_사용불가라는 폴더명만 보고 포기하지 않고 법원 긴급사유서·기술지원협약서·심의결과서도 확인했지만 RFP를 대체하지 못했다.
2. 원문에서 확인된 마감·참가자격·표 간 차이를 실제 입찰에 적용할 최종 단일값으로 결정하려면 정정공고·발주기관 답변이 필요하다. 해당 자료를 확보하기 전에는 출처별 값 또는 판단보류를 정답으로 쓴다. 발주기관에 연락하지 않았다.
3. 표·수식의 추출 불완전은 오류를 임의 복원하지 않는다. 이번 검토에서 확정하지 않은 원본 수식·경계기호는 정답 계산에 사용하지 않는다.

부산시 [공식 공고 게시물](https://www.busan.go.kr/nbgosi/view?gosiGbn=A&sno=78096)의 첨부는 공고문 HWPX로 표시되며, 본문은 평가기준을 RFP로 안내한다. 별도 RFP는 확보하지 못했다. 나라장터 상세 링크는 웹 도구에서 열리지 않아 최신 첨부·정정 이력 전수 확인은 완료하지 못했다. 민간 재게시 사이트 검색 결과는 정답 확정 근거로 채택하지 않았다.
