## 질문·기업 자료 생성에 사용할 때

- 원문 청크는 별도 RAG 검색 자료로 구축하고, 이 CSV는 요건·근거 위치·검토 쟁점의 기준표로 사용한다.
- 질문별로 공고번호·차수, 대상 조건, 원본 파일, 쪽수 또는 절/표/요구사항 ID, 실제 근거 구절을 연결한다. 쪽수 미확인은 목차 숫자로 대체하지 않는다.

- 없음·미확인·첨부 미확보를 구분한다. 문서 충돌은 두 값을 보존하고, 확정되지 않은 조건은 판단보류·추가확인 시나리오에 쓴다.

- 질문·기대답·근거 초안 생성과 실제 모델 답변의 환각 구간 라벨링은 별도 단계다.
