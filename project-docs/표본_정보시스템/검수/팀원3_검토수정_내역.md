# 팀원3 요건추출시트 검토 수정 내역

제출 원본은 수정하지 않았다. 원본 공고 HWP/PDF를 새로 대조한 사실 검증본이 아니라, 제출 시트의 내부 일관성과 확정·미확인 구분을 보완한 수정본이다. 담당 10건, 원래 15개 열과 서식을 유지했다.

변경 원칙: 확인된 금액·날짜·쪽수는 임의 교체하지 않는다. 원문 기재, 기존 추출, 추가 검토가 필요한 해석을 구분한다. 미확인 항목은 자동 정답 생성 시 보류하거나 근거 부족 응답의 검토 대상으로 사용한다.
