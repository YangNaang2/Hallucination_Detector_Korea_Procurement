# 요건 추출 시트 작성 요령

대상: 팀원 5명. 각자 `배분표.csv`의 자기 공고 10~11건. 공고당 30분, 총 5~6시간. 기한 9/13(일) 밤.
파일: `요건추출시트.csv`(공고번호·제목·기관·예산은 채워져 있음). 자기 행만 채워서 같은 파일명으로 제출.

## 어디를 읽나

`표본_정보시스템/<공고번호>/원본/` 의 **공고문(입찰공고서)** 과 **제안요청서 또는 과업지시서** 두 개면 충분하다. 내역서·서식·계약예규·상생결제 안내는 읽지 않는다.
HWP가 안 열리면 같은 이름의 `텍스트/*.jsonl`(구간별 텍스트)을 메모장으로 열어도 된다.

## 열별로 적는 것

| 열 | 적는 내용 | 예시 |
|---|---|---|
| 참가자격_업종면허 | 참가 자격에 요구하는 업종·면허·신고 | 소프트웨어사업자 신고, 정보통신공사업, 직접생산확인 |
| 실적조건_금액건수기간 | 유사 실적 조건. 금액·건수·기간을 숫자 그대로 | 최근 5년 내 유사 사업 1건 이상, 3억 원 이상 |
| 투입인력_등급인원자격 | 요구 인력 등급·인원·자격증 | PM 특급 1인, 고급 2인, 정보처리기사 |
| 인증요구 | ISO, CMMI, GS인증, 클라우드 보안인증 등 | ISO 9001 및 27001, GS 1등급 |
| 예산_추정가_하도급비율 | 사업 예산, 추정가격, 부가세 포함 여부, 하도급 제한 | 배정예산 3억(부가세 포함), 하도급 50% 이하 |
| 일정 | 입찰 마감·개찰·제안설명회·사업 기간 | 마감 5/20 10:00, 사업 기간 계약일~12/31 |
| 평가배점 | 기술·가격 배점, 주요 평가 항목 | 기술 90 : 가격 10, 수행 실적 10점 |
| 특이조건 | 지역 제한, 공동수급 허용 여부, 보안 요구, 중소기업 제한 | 경기도 소재 업체, 공동수급 불허, 보안서약 |
| 근거문서_쪽수 | 위 내용이 있는 문서명과 쪽 또는 항목 번호 | 제안요청서 5쪽 3.2, 공고문 2쪽 |
| 검토메모 | 애매한 것, 문서끼리 모순, 숫자가 두 군데 다르게 적힌 경우 | 공고문은 3억, RFP는 2.9억 |

## 원칙

- **문서에 적힌 대로만.** 추측·요약하지 않는다. 없으면 "없음". 못 찾았으면 "미확인".
- **숫자는 원문 표기 그대로.** "300,000,000원" 이면 그대로. 단위 바꾸지 않는다. 숫자 대조 규칙의 정답이 된다.
- **모순은 메모에.** 공고문과 제안요청서 숫자가 다르면 둘 다 적고 메모에 표시. 이런 곳이 환각 유도에 가장 좋은 재료다.
- 한 셀에 여러 항목이면 `;` 로 구분.

## 이 시트가 어디에 쓰이나

- 가상 기업 5곳의 실적·인력·인증·단가를 이 조건들에 맞춰 설계한다 (어떤 기업은 충족, 어떤 기업은 미충족, 어떤 항목은 자료 없음).
- 검수 질문 300개의 정답 근거가 된다.
- 숫자 대조 규칙 검증의 기준값이 된다.
