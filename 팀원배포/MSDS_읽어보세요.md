# MSDS 환각 탐지 — 읽어보세요

B1조 · 검증 모델 파트에서 만든 꾸러미입니다. **GPU 없는 노트북에서 돌아갑니다.**

---

## 1. 이 프로젝트가 뭔가요

AI 챗봇에게 문서를 주고 답하게 해도, 챗봇은 **그 문서에 없는 내용을 지어냅니다.**
저희는 답변에서 **문서로 뒷받침되지 않는 구절만 골라 형광펜을 긋는 모델**을 만들고 있습니다.

판정 기준이 **"이 말이 사실인가"가 아니라 "이 문서에 있는가"** 라는 점이 중요합니다.
사실이어도 그 문서에 없으면 형광펜이 칠해집니다. 전문 지식이 없어도 판단할 수 있는 이유입니다.

적용 대상으로 **MSDS(물질안전보건자료)** 를 골랐습니다. 응급조치나 노출 기준이 틀리면
사람이 다치는 문서이고, 16개 항목이 법으로 고정돼 있어 "문서에 있다/없다"가 분명합니다.

---

## 2. 지금까지 어디까지 왔나요

**공개 데이터(영어)를 한국어로 번역해 모델을 학습시켰고, 성능이 나왔습니다.**

| 단계 | 결과 |
|---|---|
| 영어 자료를 표시 보존한 채 한국어로 번역 | 1.7만 건 · 표시 98% 보존 |
| 모델 학습 (3종 비교) | 최고 **macro F1 0.7385** (해외 선행 연구 0.7266 을 넘음) |
| 번역 손실이 있는지 확인 | **없음.** 영어 원본으로 학습해도 오히려 더 낮았음 |
| **MSDS 로 옮겨서 재기** | **AUROC 0.8140** (벤치마크 0.8834 에서 −0.069) |

마지막 줄이 이 프로젝트가 내놓기로 한 숫자입니다. **학습에 없던 도메인(화학·법령)인데
판별력이 0.07 밖에 떨어지지 않았습니다.** "번역해서 만든 학습 자료가 실제 한국어
문서로 넘어간다"는 뜻입니다.

이 꾸러미에 들어 있는 모델은 **klue** 입니다. 성능이 조금 낮은 대신(AUROC 0.7941)
작고 빨라서 **GPU 없이 노트북에서 돌아갑니다.**

## 3. 하실 일은 두 가지입니다

### (1) 형광펜 앱으로 확인하기 — 30분

`msds` 폴더에 **톨루엔 52문항**이 들어 있습니다. 사람이 미리 정답을 표시해 둔
문항이라, 모델이 무엇을 잡고 무엇을 놓치는지 눈으로 볼 수 있습니다.

앱을 켜고 왼쪽에서 예시를 골라 **검사하기** 를 눌러 보세요.

**특히 이런 걸 봐 주세요.**

- **숫자를 틀린 문항** — 문서엔 6개월인데 답변이 12개월이라고 한 것 같은 경우.
  지금 모델이 여기서 가장 많이 실패합니다.
- **긴 문장을 통째로 지어낸 문항** — 이건 비교적 잘 잡습니다.
- **멀쩡한 답변에 형광펜이 칠해진 경우** — 있으면 어느 문항인지 알려 주세요.

### (2) 실제 LLM 답변 모으기 — 이게 더 중요합니다

지금 52문항은 **사람이 환각을 일부러 심어서 만든 것**입니다. 실제 AI 가 내는
실수와는 모양이 다릅니다. **진짜 성능을 재려면 LLM 이 스스로 만든 답변이 필요합니다.**

앱에서 **「답변 생성 모드 켜기」** 를 체크하면 방법이 나옵니다.

**권장 방법 — 웹 LLM 복붙 (GPU 필요 없음)**

1. 왼쪽 **문서 조각 골라 넣기** 에서 문서를 하나 고릅니다
2. **질문** 칸에 질문을 적습니다
3. **프롬프트 만들기** 를 누르고 나온 글을 복사합니다
4. **ChatGPT 나 Gemini** 에 붙여넣고 답변을 받습니다
5. 그 답변을 **검사할 답변** 칸에 붙여넣고 **검사하기**
6. 오른쪽 **이 답변 저장** 을 누릅니다 (어디서 만들었는지 꼭 적어 주세요)

상용 모델의 답을 쓰는 게 오히려 낫습니다. **"최신 모델도 지어낸다"** 를 보이는 게
이 프로젝트의 요지이기 때문입니다.

**목표는 20~30건입니다.** 다만 그냥 물으면 챗봇이 문서를 잘 따라가서 환각이 잘
안 나옵니다. **환각이 나오게 하려면 이렇게 물어보세요.**

| 질문 방식 | 예 |
|---|---|
| **문서 옆을 묻기** | 문서에 노출기준만 있는데 "초과하면 어떻게 처벌받나요?" |
| **다른 물질을 묻기** | 톨루엔 문서를 주고 "에탄올의 인화점은?" |
| **두 항목을 엮기** | "인화점이 낮은데 보관 온도는 몇 도로 해야 하나요?" |
| **단정을 유도하기** | "임산부는 이 작업을 하면 안 되는 거죠?" |

환각이 안 나온 답변도 **그대로 저장해 주세요.** 멀쩡한 답변에 형광펜이 칠해지는지
(= 오탐) 재는 데 꼭 필요합니다. 절반쯤은 정상 답변이어야 합니다.

## 4. 설치와 실행

**윈도우** — `윈도우_MSDS실행.bat` 더블클릭
**맥** — `맥_MSDS실행.command` 더블클릭

처음 한 번은 필요한 프로그램을 내려받느라 **5~10분** 걸립니다. 창을 닫지 마세요.
끝나면 브라우저가 저절로 열립니다. **검은 창은 켜 둔 채로 두세요.** 닫으면 앱이 꺼집니다.

파이썬이 없다고 나오면 https://www.python.org/downloads/ 에서 설치하시고,
설치 화면 아래쪽 **"Add Python to PATH"** 를 꼭 체크해 주세요.

## 5. 숫자를 직접 뽑고 싶다면

```
python 채점.py
```

`msds` 폴더의 문항을 전부 채점해서 **`채점결과.md`** 를 만듭니다. CPU 라 몇 분 걸립니다.
새 물질 파일(자일렌·메탄올 등)을 `msds` 폴더에 넣으면 자동으로 함께 채점됩니다.

**임계값(민감도)을 결과를 보고 바꾸지 마세요.** 같은 데이터로 기준을 정하고 채점하면
숫자가 부풀려집니다. 기본값 그대로 쓰시고, 바꿔야 할 것 같으면 먼저 알려 주세요.

## 6. 이미 알고 있는 약점 — 발견하셔도 놀라지 마세요

**숫자를 잘 못 잡습니다.** 문서에 6개월인데 답변이 12개월이어도 자주 놓칩니다.
크기가 5배 다른 두 모델이 **똑같은 비율로 실패**했기 때문에, 모델을 키워서
해결될 문제가 아니라 **학습 자료의 한계**로 보고 있습니다.

**"문서에 없습니다" 같은 답변에 형광펜이 잘 칠해집니다.** 그 문장 자체가
문서에 없는 말이라 그렇습니다. 알려진 실패 방식입니다.

**환각 3건 중 1~2건은 놓칩니다.** 대신 **칠한 것의 4분의 3은 맞습니다.**
적게 칠하지만 칠하면 맞는 쪽입니다.

이런 걸 찾으시면 **그대로 알려 주세요.** 감추는 것보다 설명할 수 있는 게 낫습니다.
**한계를 아는 것이 결과입니다.**
