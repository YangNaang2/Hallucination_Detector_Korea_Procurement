# 오늘 배포 · 팀원 시작 안내

배포 대상: feature/sample-expansion-demo 브랜치의 저장소 전체. 이 안내 폴더만 복사하면 실행되지 않습니다.

## 1. UI 담당자는 모델 없이 바로 시작

Git과 Python 3.10 이상 설치 후 새 작업 폴더에서:

```text
git clone --branch feature/sample-expansion-demo https://github.com/YangNaang2/ko-lettucedetect.git
cd ko-lettucedetect
git switch -c ui/본인담당-이름
python demo-ui/spatial-poc/integrated_server.py --generator disconnected --port 8769
```

브라우저: http://127.0.0.1:8769/rag-observatory.html
지도: http://127.0.0.1:8769/public-notices.html
Windows는 이 폴더의 화면실행.cmd로도 실행합니다. 종료는 서버 터미널에서 Ctrl+C.
기존 작업본은 변경을 보존하고 fetch하며, reset --hard를 사용하지 않습니다.

## 2. 역할 분담

| 담당 | 수정 범위 | 지시서 |
|---|---|---|
| 팀원1 | 공고 지도·검색·필터 | 팀원1 지시서 |
| 팀원2 | 질문·답변·근거 UX | 팀원2 지시서 |
| 팀원3 | 내부 검수·탐지 표시 | 팀원3 지시서 |
| 팀원4 | CSS·반응형·접근성·통합 QA | 팀원4 지시서 |

각 지시서의 실제 담당 파일을 따릅니다. API·모델·권한·원본 데이터는 통합 담당자 영역입니다. 공용 HTML/JS를 동시에 수정해야 한다면 먼저 담당자끼리 범위를 합의합니다.
각자 브랜치에서 커밋·푸시 후 feature/sample-expansion-demo로 PR을 제출합니다. 스크린샷, 테스트 결과, 미완성 항목을 포함합니다. main에 직접 합치지 않습니다.

## 3. 실제 Qwen + 환각 모델 실행 (통합 담당자)

Git에는 GGUF·학습 가중치·색인·비밀키가 없습니다. UI 작업에는 필요 없습니다.
실제 추론은 기존 색인과 모델 런타임이 갖춰진 PC에서 아래를 실행합니다.

```powershell
pwsh -File procurement-pipeline/start_rag_pilot_server.ps1 -GenerationModel qwen2.5-1.5b
pwsh -File demo-ui/spatial-poc/start_integrated.ps1 -Mode model -Review -DetectorPath <본인의_학습체크포인트_폴더>
```

이미 모델 서버가 실행 중이면 첫 명령을 중복 실행하지 않습니다. 가중치 폴더에는 config.json, tokenizer.json, tokenizer_config.json, model.safetensors가 함께 있어야 합니다. 환경 설치 및 Linux 실행은 README.md를 따릅니다.
탐지 의존성은 별도 가상환경에서 requirements-detector.txt를 사용합니다. CUDA 환경은 기존 검증된 torch 설치를 유지하며 CPU용 설정으로 덮어쓰지 않습니다. 실행할 Python에 해당 패키지가 설치되어 있어야 합니다.

선택은 서버의 DetectorPath로 합니다. 세 모델을 동시에 적재하지 않습니다. 기본 권장 시작은 작은 KLUE 체크포인트이며, 정확도 우위라는 의미는 아닙니다. BGE-M3·XLM-R도 같은 인터페이스를 사용합니다. 512/min/0.5는 조달 데이터에서 보정하지 않은 연결 설정입니다.

UI에서 실제 모델 모드를 선택하면 공개 L1 공고 검색 → Qwen 생성 → 답변 완료 후 탐지 → 의심 구절 표시로 진행합니다. 저장 재생의 과거 검수 초안과 신규 모델 결과는 구분합니다. 탐지 결과는 정답 보증이 아닙니다.

## 4. 자료 전달

- 우선 이 브랜치 링크와 이 안내를 전달합니다. 팀원에게 직접 메시지를 보내지는 않았습니다.
- 모델 필요 팀원만 별도 승인된 파일 전달 수단으로 체크포인트 폴더를 받습니다. 수신 후 model.safetensors SHA-256을 checkpoints.json과 대조합니다. 가중치는 Git에 추가하지 않습니다.
- 색인·원천은 기존 project-docs/RAG파일럿/v1/SOURCE_TRANSFER.md 절차를 사용합니다.
- 검수 화면은 로컬 개발용 별도 키로 열며 각 PC에서 자기 키를 생성합니다. L2/L3 자유 질의 인증 서비스가 아닙니다.
