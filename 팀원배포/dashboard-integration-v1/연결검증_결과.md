# 실제 모델 연결 검증 · 2026-09-15

## 실행 확인

- Python 3.13 / torch 2.14.0+cpu / transformers 4.57.6, 노트북 CPU.
- KLUE·XLM-R·BGE-M3 사용자 제공 safetensors를 실제 로드하고 합성 테스트 1건씩 추론. 모두 completed.
- 결과 구절: KLUE 3개, XLM-R 0개, BGE-M3 1개. 반환 구절의 정본 문자 offset 검사 통과. 하나의 인위적인 입력이므로 순위·정확도 지표가 아니다.
- 스모크 소요 시간 약 57/89/210초에는 체크섬 계산·프로세스 시작·라이브러리와 가중치 로드가 포함된다. 순수 추론 속도로 해석하지 않는다.
- 학습 src/dataset.py와 demo/detector.py의 입력 형식(질문/문서 + 답변) 및 0 SUPPORTED / 1 HALLUCINATED 일치 확인.
- API 연결 기본 KLUE, 길이 512·집계 min·임계값 0.5. 가벼운 CPU 연결 기준으로 선정했고 세 모델 동일 조건 성능 비교로 선정하지 않았다. 조달 임계값 보정 미실시.
- 가중치의 원본 학습 계보는 사용자 제공 파일·동봉 평가 기록 기준. 배포 체크섬은 이번 수신 파일의 식별용이다.

## 범위와 남은 작업

실제 인증을 갖춘 L2/L3 자유 질문, 모델 성능 재평가, 조달 데이터 임계값 보정, 긴 답변·큰 문서 실제 스트레스 검증, 새 PC 의존성 설치 실측, 모바일 실제 화면 검증은 미실시.
탐지는 답변 완료 후 실행하며 생성 중 토큰 탐지가 아니다. 프로세스는 요청마다 가중치를 다시 로드하므로 응답 지연이 있다. CPU 검증 중심이며 워크스테이션 GPU 성능은 측정하지 않았다.
세 모델의 장문 설정을 한꺼번에 최적화하지 않았다. BGE-M3의 더 긴 입력 용량을 이번 512토큰 설정이 모두 활용하는 것은 아니다.
내부 검수는 별도 로컬 키 기반 개발용 조회다. 최종 사람 승인 pending 유지.

## 개발 배포

오늘_배포_시작.md / README.md / 팀원1~4_작업지시서.md / 화면실행.cmd / .env.example / requirements-detector.txt / checkpoints.json을 포함한 저장소를 전달한다.
모델·색인·원천·비밀키는 Git에 추가하지 않는다. 모델 없는 UI 개발은 Python 표준 라이브러리만 필요하다. 별도 유료 API·다운로드·학습·300건 재실행은 하지 않았다.

별도 HTTP 통합 스모크도 done/completed로 통과했다. 결과와 정확한 근거 청크 ID·정본·탐지 offset은 live-integration-smoke.json에 있다. 요청당 출력 제한 128토큰으로 연결 검증했으며 일반 기본값은 384토큰이다.
