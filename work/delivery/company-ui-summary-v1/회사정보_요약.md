## UI 표시 원칙

- 모든 회사 카드에 `가상기업·합성 데이터` 배지를 표시한다.
- 등록·인증·실적은 `유효`, `만료`, `증빙 미확보`, `진행 중` 상태를 서로 다른 배지로 보여준다.
- 개별 조건 하나를 충족했다고 전체 입찰 적격으로 표시하지 않는다.
- 위 금액은 VAT 포함 합성 계약액이다. 실제 계약이나 시장가격으로 소개하지 않는다.
- 상세 인력·실적·인증 자료는 L2이며, 인건비·원가·마진·투찰전략은 L3이다.
- L2·L3 전체 자료를 공개 정적 UI 번들에 넣고 화면에서만 숨기면 안 된다. 서버에서 권한을 확인한 뒤 필요한 회사 자료만 반환해야 한다.
