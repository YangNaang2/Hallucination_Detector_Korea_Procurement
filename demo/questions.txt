# 데모용 질문 후보. `python demo/dry_run.py` 가 이 파일을 읽어 전부 돌려보고
# 어떤 질문이 시연에 좋은지 순위를 매겨 준다.
#
# 형식:  유형 | 질문
#   있음   문서에 답이 그대로 있다  → 형광펜이 거의 없어야 정상
#   숫자   문서에 없는 구체적 숫자를 묻는다  → 환각 유발
#   인접   문서가 다루는 것 옆에 있는 것을 묻는다  → 환각 유발
#   예외   조건·예외를 묻는다  → 환각 유발
#   결합   두 문단을 합쳐야 답이 나온다  → 환각 유발
#
# '#' 로 시작하는 줄과 빈 줄은 무시한다.

# ---- 문서에 답이 있는 질문 (탐지기가 조용해야 정상) ----
있음 | 졸업하려면 몇 학점을 들어야 하나요?
있음 | 복수전공은 몇 학점을 이수해야 하나요?
있음 | 계절학기는 한 번에 최대 몇 학점까지 들을 수 있나요?
있음 | 중앙도서관은 학기 중에 몇 시까지 여나요?
있음 | 학생식당 한식 정식은 얼마인가요?
있음 | 기숙사 2인실은 학기당 얼마인가요?

# ---- 문서에 없는 구체적 숫자 (환각 유발) ----

숫자 | 도서관 스터디룸을 예약할 때 최대 몇 명까지 함께 쓸 수 있나요?
숫자 | 복수전공 신청자는 매년 몇 명 정도 되나요?
숫자 | 계절학기 수강 인원이 몇 명 미만이면 폐강되나요?
숫자 | 셔틀버스는 하루에 총 몇 회 운행하나요?

# ---- 인접 정보 (환각 유발) ----
인접 | 교환학생으로 나가려면 어떤 조건이 필요한가요?
인접 | 졸업시험에 떨어지면 재응시는 언제 할 수 있나요?
인접 | 기숙사에서 취사가 가능한가요?
인접 | 학생상담센터에서 정신과 진료도 받을 수 있나요?
인접 | 공학관 A동 클린룸은 학부생도 쓸 수 있나요?

# ---- 예외·조건 (환각 유발) ----
예외 | 4학년인데 졸업 학점이 모자라면 21학점을 넘겨 들을 수 있나요?
예외 | 군휴학 중에 계절학기를 들을 수 있나요?
예외 | 학사경고를 받았는데 교외 장학금도 못 받나요?
예외 | 의예과 학생이 부전공만 하는 것은 가능한가요?

# ---- 두 문단 결합 (환각 유발) ----
결합 | 학사경고를 두 번 받은 학생이 복수전공을 신청할 수 있나요?
결합 | 직전 학기 평점이 3.6인데 계절학기 성적을 합치면 21학점을 신청할 수 있나요?
결합 | 공과대학 학생이 복수전공까지 하면 총 몇 학점을 들어야 하나요?
