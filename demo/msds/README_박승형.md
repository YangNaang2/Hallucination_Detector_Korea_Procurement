# MSDS 환각 탐지 평가 세트 (톨루엔) — v0.2

작성: 박승형 · 2026-09-08 · B1조 평가·페르소나 파트

한국어 환각 탐지 모델을 **MSDS(물질안전보건자료) 도메인**에서 평가하기 위한
예시 52문항입니다. 실제 MSDS 원문을 근거로 만들었고, 정답과 환각을 섞어
탐지율과 오탐률을 함께 잴 수 있게 구성했습니다.

---

## 1. 파일 목록

| 파일 | 용도 | 누가 씀 |
|---|---|---|
| `examples_msds_toluene.jsonl` | **앱 입력 + 평가 데이터** (52줄) | 앱 / 파이프라인 |

## 2. `examples_msds_toluene.jsonl` 스키마

한 줄 = JSON 객체 1개. 총 52줄.

```json
{
  "id": "MSDS-026",
  "question": "톨루엔의 인화점은 몇 도인가요",
  "context": "9. 물리화학적 특성\n\n가. 외관\n...(585자)",
  "answer": "톨루엔의 인화점은 40℃입니다. 끓는점은 110.6℃이며...",
  "answer_tagged": "톨루엔의 인화점은 <HAL>40℃</HAL>입니다. 끓는점은...",
  "hall_type": "숫자변조",
  "q_type": "수치",
  "source_section": "톨루엔-9",
  "hall_spans": ["40℃"]
}
```

| 필드 | 설명 |
|---|---|
| `question` `context` `answer` | **앱이 쓰는 3개.** `app_cpu.py`의 입력칸 그대로 |
| `answer_tagged` | 환각 구간을 `<HAL>…</HAL>`로 감싼 정답 라벨 |
| `hall_spans` | 태그 안 문자열만 배열로 뽑은 것 (스팬 F1 계산용) |
| `hall_type` | 환각 종류. `정답`이면 환각 없음 |
| `q_type` | 질문과 문서의 관계 |
| `source_section` | 사용한 문서 조각 ID |

### 파이프라인 연동 시 참고

- `<HAL>` 태그 형식은 `prepare_ragtruth.py` 출력과 맞추려 한 것입니다.
  실제 필드명이 다르면 이름만 바꾸면 됩니다 (내용 변환 불필요).
- `app_cpu.py`의 `load_examples()`는 추가 키를 무시하므로,
  이 파일을 `examples.jsonl`로 두면 **메타데이터는 UI에 노출되지 않습니다.**
  팀원이 정답을 미리 보는 일이 없도록 의도한 설계입니다.
- 라벨은 **이진**입니다. `hall_type`은 모델이 예측할 대상이 아니라
  결과를 유형별로 분해해 보기 위한 분석 축입니다.

## 3. 구성

**총 52문항 / 환각 스팬 40개 / 답변 평균 83자**

| 답변유형 | 수 | 의미 |
|---|---:|---|
| 정답 | 22 | 환각 없음. **오탐 측정용 대조군** |
| 지어내기 | 13 | 문서에 없는 항목·수치·절차를 만들어냄 (Evident Baseless) |
| 숫자변조 | 10 | 문서에 있는 값을 다른 값으로 (Evident Conflict) |
| 과일반화 | 4 | 문서 범위를 넘어선 단정을 덧붙임 |
| 의무예외 | 3 | 의무와 예외, 조건과 결론을 뒤바꿈 (Subtle Conflict) |

| 질문유형 | 수 | 의미 |
|---|---:|---|
| 있음 | 22 | 문서에 답이 그대로 있다 |
| 수치 | 16 | 구체적 숫자를 묻는다 |
| 인접 | 10 | 문서가 다루는 항목 "옆"을 묻는다 |
| 교차 | 3 | 톨루엔 문서인데 다른 물질을 묻는다 |
| 결합 | 1 | 두 항목을 합쳐야 답이 나온다 |

정답을 22개로 잡은 이유: 이게 없으면 "전부 빨갛게 칠하는 모델"과
구별할 수 없습니다. 탐지율만 보면 안 되고 오탐률과 같이 봐야 합니다.

## 4. 데이터 출처

**톨루엔 MSDS** — 안전보건공단 화학물질정보 (msds.kosha.or.kr, chem_id=001032),
CAS 108-88-3, 최종 개정일 2025-08-08. 공공누리 제2유형(출처표시+상업적 이용금지).

MSDS는 산업안전보건법 제110조·제111조에 따라 화학물질을 양도·제공하는 자가
작성해 제공해야 하는 자료이며, **16개 항목의 순서가 법으로 고정**돼 있습니다.
이 고정 구조 덕분에 어느 항목에 무슨 정보가 있어야 하는지가 명확해
답변이 문서를 벗어났는지 판정하기 쉽습니다.

`context`는 원문 PDF를 텍스트로 변환한 뒤 16개 항목 단위로 자른 것이며,
2번과 11번은 분량이 길어 각각 둘로 나눠 **총 18조각**입니다.

| 조각 | 항목 | 글자 | 조각 | 항목 | 글자 |
|---|---|---:|---|---|---:|
| 톨루엔-1 | 화학제품·회사 정보 | 159 | 톨루엔-9 | 물리화학적 특성 | 585 |
| 톨루엔-2a | 분류·신호어·H문구 | 585 | 톨루엔-10 | 안정성·반응성 | 469 |
| 톨루엔-2b | 예방조치문구(P문구) | 1,149 | 톨루엔-11a | 독성(급성) | 214 |
| 톨루엔-3 | 구성성분·함유량 | 77 | 톨루엔-11b | 독성(발암성 등) | 1,255 |
| 톨루엔-4 | 응급조치요령 | 650 | 톨루엔-12 | 환경 영향 | 498 |
| 톨루엔-5 | 폭발·화재 대처 | 861 | 톨루엔-13 | 폐기시 주의사항 | 266 |

## 5. 이 세트를 만들 때 지킨 원칙

**안전.** 4·5·6번 항목(응급조치·소화·누출대처)에서는 행동 지시 자체를
뒤집지 않았습니다. 숫자·절차·근거만 틀리게 했고, 따라 하면 위험해지는
오답은 만들지 않았습니다. 초안에 있던 응급조치 세척 시간·해독제 문항 2건은
이 원칙에 따라 삭제했습니다.

**스팬 크기.** 답변 전체를 틀리게 만들지 않고 한두 군데만 어긋나게 했습니다
(문항당 평균 1.3스팬). 실제 LLM 환각이 그런 모양이고, 전체가 틀리면
탐지가 지나치게 쉬워집니다.

**사실 vs 근거.** 교차 문항(50·51번)의 에탄올 인화점 13℃ 등은
**사실로는 맞지만 톨루엔 문서에 없는** 값입니다. 사실 여부와 문서 근거
여부가 갈리는 지점이라, 모델이 무엇을 기준으로 판단하는지 드러납니다.

## 6. 알아두실 점

**도메인 외 데이터입니다.** 학습 데이터가 RAGTruth 번역본이라면 도메인은
뉴스 요약·data-to-text·QA이고, 한국어 기술·법령·화학 문서는 없습니다.
학습 텍스트는 기계번역 한국어인데 MSDS는 원어민 격식체 기술 문서라
문체 분포도 어긋납니다. **탐지율이 낮게 나오는 것이 예상 범위입니다.**
이 세트의 목적은 성능 자랑이 아니라 **도메인 일반화 능력 측정**입니다.

**유형별 기대 차이.** 숫자변조는 번역을 거쳐도 숫자가 살아남으므로
상대적으로 잘 잡힐 가능성이 있고, 문체·논증 구조에 의존하는
과일반화와 의무예외는 많이 놓칠 것으로 봅니다.

**의무예외 3개, 과일반화 4개로 얇습니다.** 유형별 탐지율을 비교하려면
각각 6~8개는 필요한데, 톨루엔 MSDS가 "~하시오" 형태의 단정적 지시문
위주라 뒤바꿀 조건절이 부족했습니다. 늘리려면 산업안전보건법 시행규칙
제156·157·159·160조나 고시 제11조(작성원칙)를 조각으로 추가해야 합니다.
거기는 "다만 ~인 경우에는 그러하지 아니하다"가 많습니다.

**예상되는 오탐 자리.** 3·39·52번은 "문서에 없습니다" 류의 진술이
들어갑니다. 이런 답변은 그 문장 자체가 문서에 없는 말이라 형광펜이
잘 칠해집니다. 알려진 실패 모드가 MSDS에서도 재현되는지 보려고
일부러 넣었습니다.

## 7. 채점 방법

1. 임계값 **0.35 고정**으로 52문항을 한 바퀴 돕니다
2. `answer_key_toluene.pdf`의 음영과 대조합니다
   - 음영 자리에 형광펜 → **탐지 성공**
   - 음영 없는 정답 문항에 형광펜 → **오탐**
   - 음영 있는데 형광펜 없음 → **누락**
3. 스팬이 정확히 일치하지 않아도 **겹치기만 하면 탐지**로 셉니다

RAGTruth 기준 스팬 단위 F1 상한이 52.7%라, 완전 일치를 요구하면
대부분 실패로 집계됩니다. 실사용 관점에서도 "확인이 필요한 구간을
가리키는가"가 중요하지 경계가 정확한지는 부차적입니다.
